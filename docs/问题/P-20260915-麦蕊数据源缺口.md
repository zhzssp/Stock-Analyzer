## 0. 结论

**不完全是「API 里什么都没有」。** 要拆成三档，不能写成一句「麦蕊无源」。

| 图 1 | 需求要点 | 判定 | 一句话 |
|---|---|---|---|
| ⑤ | 彭博等站点快讯 + 链接，可能影响自选则提醒 | **确认无源** | 公开接口里没有新闻 / 检索 / 舆情 |
| ④ | 关联品种近一周行情、连涨连跌 3 日 | **确认无行情** | 只有期货分类树，没有品种 OHLC |
| ⑦ | 出口占比、外市场占比 | **确认无字段** | 利润表只有合计营收；资产负债表「应收出口退税」不是占比 |
| ⑥ | 自选**每日**北向 | **个股日频确认盖不住** | 全市场北向有路径；个股日频持股上游已停更；因子 `north_*` 官方仍空 |
| ② | 并购 / 激励 / 减持 / **回购起止** / 巨潮正文 | **有公告列表，盖不住结构化事件** | `announcement.lx` 只有「其他 / 财报」；无起止日；本仓库只拼了巨潮链接 |

已经接通、本次**不当缺口**的：个股资金流入/流出/净流入（`history/transaction`，特大/大/中/小单）、基金持股 `hscp/jjcg`、分红/增发/解禁、申万一级/七大板块本地主数据、期货**品种映射**（无价格）。

## 1. 确认无源（等第二数据源或手工表）

这三档在官网 hsdata 全文、官方 SDK 方法表里都没有对应接口。不需要再猜「是不是文档漏写」——漏写的南北向已经出现在 SDK 的「沪深数据中心」章节，资讯 / 期货行情 / 出口占比没有同类章节。

### 1.1 ⑤ 彭博 / 财经站点检索

hsdata 现有分类止于：列表、股池、公司资料、股东、实时、资金流向（单档口径）、K 线/指标、三张报表、涨跌停/竞价、**问董秘、交易所公告**。

全文检索「新闻 / 资讯 / 微博 / 彭博 / 搜索 / 舆情」：只有概念树里的股票名「卓创资讯」，没有资讯接口。

SDK `API_METHOD_MAP.md` 的公开方法同样没有 search / news / bloomberg。

**本仓库：** `web_finance_search`、`policy_news` 保持 `enabled: false`（Agent 仍不能全网搜）。监控偏好可配检索源白名单，日终只抓这些 URL；未配源时「资讯冲击 / 产业政策」仍禁用。不爬未授权站点、不编快讯。

### 1.2 ④ 期货近一周 / 3 日同向

`hszg/list` 的 `type1=8` 是**分类树**（全球期货、中金所、上期所、大商所、郑商所）。叶子 `code` 只能再丢给 `hszg/gg` 找**相关股票**，文档没有「用该 code 拉期货 K 线」的接口。

利润表字段 `qhsy` 是上市公司「期货损益」，不是铜、原油、生猪的报价。

基金 / ETF 的 `/jj/*`、`/fd/*` 是场内基金行情，不能当商品期货。

**本仓库：** `futures_map` 只给关联品种名；`futures_quote` 关闭；监控「期货联动」显示未启用。

### 1.3 ⑦ 出口 / 外市场占比

`hsstock/financial/income` 有 `yysr` / `yyzsr`（营业收入合计），没有分地区、出口、海外收入或占比。

资产负债表有 `ysckts`（应收出口退税），是应收款科目，不是收入结构。

**本仓库：** `export_share` 只读 `data/export_share.csv`；没有文件就空，不编占比。

## 2. 有路径，但盖不住图 1 口径

### 2.1 ⑥ 北向：全市场有，个股每日没有

图 1 要的是**自选每一只、每个交易日**的北向，和已经接通的「流入 / 流出 / 净流入」同一粒度。

**禁止替用：** `hsstock/history/transaction` 的说明写明特大/大/中/小单（金额或手数阈值）。这是订单结构，不是沪股通/深股通。本仓库的 `flow_in` / `flow_out` / `flow_net` 走的就是它，**不能再填进 `northbound`**。

**全市场北向（2026-08-06 日志「南北向资金系列」；SDK 1.2.0 已列路径）：**

| 能力 | 路径 | 粒度 |
|---|---|---|
| 当日南北向概览 | `/ht/nbzj/lxgl/{licence}` | 通道合计（万） |
| 北向历史走势 | `/ht/nbzj/bxls/{jd}/{licence}` `jd=1\|6\|12\|all` | **全市场**每日净流入（百万） |
| 沪/深股通历史 | `/ht/nbzj/hgls` `/ht/nbzj/shls` | 通道每日，不是自选一行 |
| 沪/深股通十大成交 | `/ht/nbzj/hgts` `/ht/nbzj/sgts` | 近 30 日**前十名**才有个股净买额 |
| 成分股行情 | `/ht/nbzj/hgtc` `/ht/nbzj/sgtc` | 普通行情字段，**无北向净买** |
| 北向个股周期排名 | `/ht/nbzj/bxpm/{zq}/{licence}` | 见下 |

`bxpm` 的官方口径（SDK `API.md`，2026-08 标注）：

> 上游北向个股**日频持股明细已停更**，本接口降级为「季频持股快照」。  
> 周期增持类字段（`zq*`）当前多为 null。不再提供 d/3/5/10/m/q/y 等多周期日频增持排名。

这与因子文档、FAQ 一致：`north_5d_net` / `north_20d_net` / `north_holding_ratio` **因数据源待接入按设计返回空**（FAQ 第 6 条；首页 Quant Pro 说明同样写「待开放」）。因子算法注释里的原料 `/hsgt/stock/{code}` **没有**出现在 hsdata，也**没有**出现在 SDK 方法表。

hsdata 页面本身仍然没有 `hsgt` / `nbzj` 条目；南北向写在「沪深数据中心」，不在「沪深基础数据」。

**对图 1 的含义：**

- 做「全市场北向曲线 / 是否沪深股通标的」——文档路径在，正式 licence 联调后可以接。
- 做查询表上每只自选的**每日北向列**——**当前官方口径盖不住**（日频个股停更 + 因子空 + 十大成交只覆盖前十）。
- 本仓库 `northbound` 继续空、界面写「未接入」，这个判断**仍然成立**。

### 2.2 ② 公告：有列表，没有并购/回购类型，没有起止日

2026-07-18 日志新增，hsdata 与 SDK 均已列出：

```
GET https://api.mairuiapi.com/hsstock/announcement/{stock_code}/{licence}
```

文档字段：`t` 时间、`zt` 主题、`zy` 摘要、`gs` 格式、`nr` 公告链接、`jb` 级别、`lx` 类型。

**`lx` 只定义了两个值：`0` 其他，`1` 财报类。** 没有并购、回购、激励、减持枚举，也没有回购起始日 / 结束日。

同日开放的问董秘 `/hsstock/interactiveqa/{code}/{licence}` 是问答（`q`/`a`），不是公司事件表。

本仓库 `MarketClient.events()` 仍只拉 `hscp/jnfh`、`jnzf`、`jjxs`，再拼巨潮检索页：

`https://www.cninfo.com.cn/new/disclosure/stock?orgId=&stockCode={code6}`

这是链接，不是公告正文，也不是分类后的回购日历。

数据中心另有 `/hitc/jrts`（今日交易提示，含沪深公告标题串），是**全市场当日概览**，不能替代按代码、按类型、带起止日的事件。

`hscp/yjyg` 是业绩预告，不是并购/回购。

**对图 1 的含义：** 接 `announcement` 只能得到标题 + PDF 链接 +「是不是财报」。要「回购开始/结束」必须另做结构化源，或在正式 licence 下抽样看标题能否稳定解析——**解析不是 API 能力，本文不把它算作已有数据源。** 不爬巨潮。

## 4. 对本仓库的约束

1. ⑤④⑦：**确认无麦蕊源**。继续插槽 / 手工表，不编价格、不编新闻、不编占比。
2. ⑥：**不要**用 `transaction` 冒充北向。全市场 `/ht/nbzj` 是否接线，等正式 licence 联调另开任务；查询列「个股每日北向」在上游日频恢复或第二源到位前保持未接入。
3. ②：不要把 `announcement` 标成「并购/回购已接通」。最多是未分类公告列表。
4. 关闭本单的条件（任一对应项满足即可拆单关闭）：
   - ⑤ 有授权资讯 API 或明确的手工源；
   - ④ 有期货 OHLC 源，且能按品种拉满近一周；
   - ⑦ 报表出现分地区收入，或手工表成为约定输入；
   - ⑥ 官方恢复个股日频北向（或 FAQ 撤销 `north_*` 空值声明）并经正式 licence 抽到非空；或产品改口径为「全市场北向 + 是否通标的」；
   - ② 出现带类型/起止日的事件接口，或产品接受「标题列表 + 链接」并单独验收。
