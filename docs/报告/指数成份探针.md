# 指数成份探针

> 由 `scripts/Verify-Index.ps1` 更新。工作台现网用 `hszg/gg/zhishu_{6位}` 拉成份；本文件记探针落盘结果。

## 口径

- 上证指数 / 深证成指 / 北证50 / 科创综指 / 创业板指 / 中证500 / 上证50 是**该指数成份股**。
- 深证成指 ≠ 深市全部；北证50 ≠ 北交所全部。不得用 `hslt/list` 按交易所切片冒充这些名字。
- 盘点里已有的 `hscp/sszs/{code}` 是**个股反查所属指数**，不是「指数 → 成份」。
- 用全市场股票逐个打 `sszs` 拼成份默认**不做**（约 5000 次请求，且演示 licence 无意义）。

## 官方路径（hsdata，2026-09-21 已实测）

1. `GET /hszg/list/{licence}`，取 `type2=7`（A股-指数成分）且 `isleaf=1` 的节点。
2. `GET /hszg/gg/{tree_code}/{licence}`，例如上证指数 `zhishu_000001`。

| 指数 | 树代码 | 实测条数（正式 licence） |
|---|---|---|
| 上证指数 000001.SH | `zhishu_000001` | 2228 |
| 深证成指 399001.SZ | `zhishu_399001` | 500 |
| 北证50 899050.BJ | `zhishu_899050` | 50 |
| 上证50 000016.SH | `zhishu_000016` | 50 |
| 中证500 000905.SH | `zhishu_000905` | 500 |
| 创业板指 399006.SZ | `zhishu_399006` | 100 |
| 科创50 000688.SH | `zhishu_000688` | 50（点位用；不是科创综指） |
| 科创综指 000680.SH | 无节点 | 树里没有，芯片保持未启用 |

猜过但不存在的路径：`/hsindex/constituent|chengfen|component|weight/{code}` 均为 404。

## 运行

```powershell
.\scripts\Verify-Index.ps1 -Licence $env:MAIRUI_LICENCE
```

演示 licence 的结论只能是「无法验证」，芯片不得打开。
