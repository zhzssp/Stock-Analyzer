# 指数成份探针

> 由 `scripts/Verify-Index.ps1` 更新。正式 licence 未跑通前，工作台用离线成份切片，不得把全市场写成指数。
>
> 当前仓库默认：离线 / 未实测。本文件只记实盘探针，不要手改正文。

## 口径

- 上证指数 / 深证成指 / 北证50 / 科创综指 / 创业板指 / 中证500 / 上证50 是**该指数成份股**。
- 深证成指 ≠ 深市全部；北证50 ≠ 北交所全部。不得用 `hslt/list` 按交易所切片冒充这些名字。
- 盘点里已有的 `hscp/sszs/{code}` 是**个股反查所属指数**，不是「指数 → 成份」。
- 用全市场股票逐个打 `sszs` 拼成份默认**不做**（约 5000 次请求，且演示 licence 无意义）。

## 候选路径（正式 licence 时由脚本尝试）

- `/hsindex/constituent/{code}`
- `/hsindex/chengfen/{code}`
- `/hsindex/component/{code}`
- `/hsindex/weight/{code}`
- `/hslt/zs/{code}`

命中且条数足够时写入 `data/index_probe.json`，对应 `index:{code}` 才会 `enabled=true`。

## 运行

```powershell
.\scripts\Verify-Index.ps1 -Licence $env:MAIRUI_LICENCE
```

演示 licence 的结论只能是「无法验证」，芯片不得打开。
