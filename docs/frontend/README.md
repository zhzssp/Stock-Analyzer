# 前端设计稿

视觉原则：浅底、少装饰、青绿点缀，表和对话共用同一套工作台，而不是两套皮肤。

| 文件 | 用途 |
|---|---|
| `workbench-query.png` | 传统查询主界面效果图 |
| `workbench-agent.png` | Agent 问答 + 当日监控效果图 |
| `index.html` | 可切换「查询 / 问答 / 监控」的本地原型 |

工作台已接到本机 FastAPI（登录、自选、查询、列设置、导出、问答、监控）。侧边「行情」选指数成份（上证指数 / 深证成指 / 北证50 等），查询和导出只含成份股。请用 `.\scripts\run-server.cmd` 启动后访问 http://127.0.0.1:8765 ，不要直接双击 HTML（否则 `/api` 不存在）。
