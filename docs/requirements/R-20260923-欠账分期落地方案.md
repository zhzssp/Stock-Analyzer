## 2. L1 本机闭环（建议先做）

### L1-1 U18 退出登录

- 后端：新增 `POST /api/auth/logout`（清 `sa_token`），位置 `src/api/routes.py` `/auth/login` 附近。
- 前端：顶栏退出按钮，清本地 token 后回登录页（`docs/frontend/index.html`）。
- 验收：点退出即回登录态；不刷新也能再登录。

### L1-2 U19 自选分组

- `POST /watchlist/items` 接受 `group`（当前 `routes.py:408` 写死「自选」）；`PUT /watchlist` 批量走同一规则（`:364` 已有解析逻辑）。
- 侧栏按分组视图 + 筛选器（分组集合见 `routes.py:374` 的 `GROUPS`）。
- 验收：添加时可选组、侧栏按组看、按组筛选；决策卡改组（`:473`）与批量添加结果一致。

### L1-3 U11 提醒通道（只做 Webhook 表单）

- `MonitorPref` 增 `webhook_url`（`MonitorPrefIn` / `save_pref`）；`src/platform/channels.py:27 notify_webhook` 优先取用户配置，回落 `settings.alert_webhook`。
- 通道名 `desktop` 易误解，改名或加说明（`channels.py:61`）。
- **不做**：OS 气泡、微信；对客已写明无手机微信。
- 验收：工作台填 URL → 命中即推送；留空则只进日志与监控列表。

### L1-4 U12 盯盘快照对用户开放

- 新增只读 API（如 `GET /monitor/snapshots`）列/导出「今早对照」；数据源为 DB `snapshots`，**与查询表快照 `data/snapshots/` 区分**。
- 验收：能列出今日快照并导出；watcher 差分行为不变。

### L1-5 U4 监控资讯/政策收尾

- 去重键细化：由 (job + 股票 + 当天) 改为加 URL 指纹（同日同 URL 只进一条）。
- Agent 共用同一白名单（关闭 U2/U3 的监控侧，不是全网检索）。
- 政策源与资讯源的匹配规则差异写进对客说明。
- **不做**：LLM 摘要、渲染页、登录墙（见 U20）。
- 验收：同 URL 不重复进今日；Agent 问答能引用白名单命中并带 URL。

### L1-6 查询行外链

- 需求 [`R-20260921-查询行外链验证`](./R-20260921-查询行外链验证.md)：把零散的 `cninfo_url` 做成查询行可点外链（巨潮等官方页）。
- 验收：查询行外链可点、只指向官方/已验证域名。

## 3. L2 有源才做（逐条开，源到哪条开哪条）

每条先做「证源 30 分钟」，证不到就直接走**关闭口径 B**，不空转。

| 欠账 | 前置（源） | 开通后做什么 | 关闭口径 B（无源时如何收口） |
|---|---|---|---|
| **U1** 期货行情/联动 | 品种 OHLC 或结算价源 | 开 `src/tools/manifests/futures_quote.yaml`；`futures_map` 返回 `quote`；监控 `futures` 去 `reason` | 保持灰卡 + `gaps` U1，对客不提期货价格 |
| **U2** Agent 财经检索 | 授权新闻源/API | 开 `web_finance_search.yaml`，结果带 URL，空命中返回空 | 保持关闭，对客写明「只查你配过的源」 |
| **U3** Agent 政策检索 | 授权政策源 | 同 U2（`policy_news.yaml`） | 同 U2 |
| **U5** 个股日频北向 | 盖得住个股日频的源 | 填 `northbound` 列，取默认勾选 | **去掉或隐藏该列**（默认不勾 + `unavailable` 已是现状），禁止用 `flow_*` 冒充 |
| **U6** 出口/海外占比 | 稳定第二源 | 自动填充 | 明确「手工表就是产品」，对客保持「没表就没有」 |
| **U8** 并购/回购等结构化事件 | 结构化事件源或公告分类可行 | 分类事件 + 起止日 | 保持只有分红/增发/解禁 + 巨潮链接，对客不承诺 |

验收统一要求：**注明来源 URL**；无命中返回空，不补编。
