# R-20260921 查询行外链验证

> 状态：**开放（待排期）**。本文记录需求与 URL 来源分析，**不是开工令**；实现前须另定方案与分期。
> 提出：2026-09-21
> 来源：用户希望在查询结果每一行前附上可跳转链接，便于在外部 UI 对照验证行内数据。

---

## 原话

对于查询出来的每一行的股票信息，应该在前面附上原始的股票信息链接，让用户可以非常方便地跳转到具体的 UI 去进行验证。

---

## 背景

- 查询表每行已有 `code6`、`code_full`、`name`、`market`（见 `QueryEngine.run`），足够识别标的。
- 本仓库已有一处外链先例：`cninfo_url(code6)`，用于巨潮披露检索页（`MarketClient.events`、监控文案），**不消耗麦蕊配额**。
- 麦蕊 API 是 JSON 接口，**不提供**「按股票打开」的官网个股详情页 URL；见 [API现状](../API/API现状.md) 与下文 §3。

---

## 产品意图（待实现时对齐）

| 维度 | 说明 |
|---|---|
| 主要场景 | 用户跑完查询/导出后，点链接在新标签页打开外部页面，对照价格、财务、公告等 |
| 放置位置 | 表格**每行最前**（名称/代码列之前或与之合并为可点区域） |
| 非目标 | 用外链数值回写查询表；替代本系统数据；默认每行额外调麦蕊 `announcement` 耗配额 |

## URL 来源分析（实现前必读）

### 结论摘要

| 方式 | 能否作为「每行主链接」 | 麦蕊配额 | 说明 |
|---|---|---|---|
| 麦蕊 API 返回个股主页 URL | **否** | — | `hslt/list`、`hsrl/ssjy`、`hscp/gsjj` 等无此字段 |
| 麦蕊 `announcement.nr` | 仅公告级 | **是**（按只请求） | 单条 PDF/静态链接，适合「最新公告」副链，不适合整行入口 |
| 按 `code_full` 拼接第三方行情站 | **推荐** | 0 | 东财 / 雪球 / 新浪等，规则稳定、维护成本低 |
| 巨潮 `cninfo_url` | **推荐（披露）** | 0 | 已有实现；验证公告与财报披露 |
| 交易所官网个股页 | 可选副链 | 0 | 沪/深/北规则不统一，部分需 `orgId` |
| 本系统 debug 原始 JSON 页 | 可选（研发） | 视实现 | 验证「麦蕊返回」本身，不是外站看盘 UI |

### A. 拼接外链（建议主方案）

查询结果组装时，由 `exchange`（SH/SZ/BJ）+ `code6` 生成，**零 API 调用**。

| 提供方 | 用途 | 模板（`ex` = sh/sz/bj 小写，`code6` = 六位） |
|---|---|---|
| 东方财富 | 行情、财务、股东对照 | `https://quote.eastmoney.com/{ex}{code6}.html` |
| 雪球 | 行情 + 社区 | `https://xueqiu.com/S/{EX}{code6}`（`EX` 大写） |
| 新浪财经 | 行情 | `https://finance.sina.com.cn/realstock/company/{ex}{code6}/nc.shtml` |
| 巨潮 | 公告披露 | `https://www.cninfo.com.cn/new/disclosure/stock?orgId=&stockCode={code6}`（已实现 `cninfo_url`） |

注意：科创板 `688xxx` 仍用 `sh`；北交所用 `bj`。第三方页面改版可能导致链接失效，需在实现说明中写清「非麦蕊官方页」。

### B. 麦蕊 API 中带 URL 的字段

- **`hsstock/announcement`**：`nr` 为公告链接（多在 `static.cninfo.com.cn`）。二期已接 `MarketClient.announcements`，但**不宜**在默认查询中对每行调用。
- **问董秘、资金、指标等**：无稳定「个股首页」字段。

### C. 「原始」一词的口径

| 用户可能指 | 建议 |
|---|---|
| 麦蕊 API 原始 JSON | 外链解决不了；需本系统 `/debug` 或工具页展示 raw 响应 |
| 交易所/披露权威源 | 巨潮 + 可选交易所副链 |
| 日常看盘对照 | 第三方行情站（可配置默认提供方） |

实现前应与提出人确认默认跳哪一类；文档倾向 **行情主链（可配置）+ 巨潮副链**。

## 实现约束（预定，未开工）

1. **默认不增加麦蕊请求次数**；拼接链接不得触发按行 `announcement` 等接口。
2. 外链须 `target="_blank"` + `rel="noopener"`；对客说明为第三方对照页，数值可能与表内延迟/口径不一致。
3. Excel 导出：链接列可选（HYPERLINK 或纯 URL 列），默认策略另定。
4. 提供方宜可配置（如 `LINK_PROVIDER=eastmoney|xueqiu|sina`），避免写死一家。
5. 与 [R-20260921 欠账](./R-20260921-未完成能力欠账.md) 无冲突；不冒充北向、期货等未接能力。

## 建议分期（供排期参考）

| 期 | 内容 | 验收要点 |
|---|---|---|
| **P0** | 查询表每行前 1～2 个图标链：行情（可配置）+ 巨潮 | 点击可打开正确标的；北交所/科创代码正确 |
| **P1** | 导出 Excel 含链接列；用户偏好默认提供方 | 导出文件可点击跳转 |
| **P2**（可选） | 行展开「最新公告」懒加载 `announcement.nr` | 仅用户主动展开时请求 API |
| **P3**（可选） | 本机 debug 页展示麦蕊 raw JSON | 研发验证数据源，不对客承诺 |

## 验收（关闭本需求时勾选）

- [ ] 查询结果每一行（或名称列）有可识别的外链入口，且与 `code_full` 一致。
- [ ] 至少支持一种行情站 + 巨潮；北交所、沪深主板、科创板 spot-check 通过。
- [ ] 不增加默认查询路径上的麦蕊调用次数。
- [ ] 对客功能说明补充：外链为第三方对照，非麦蕊官网。
- [ ] 离线模式（`MAIRUI_OFFLINE=1`）下链接仍可生成（仅依赖代码，不依赖 live API）。
