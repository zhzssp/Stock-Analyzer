# 数据能提供什么（白话）

> 对照日期：**2026-09-21**。麦蕊官网现网页为准；仓库里的 `新API文档.docx` 是旧清单，不要再当目录。
> 分工见 [`../INDEX.md`](../INDEX.md)。「软件里有没有这一列」以代码和对客说明为准；本文说的是**数据商已经卖什么**，以及**还没接到工作台上、但可以拿来补哪一块**。
> 前半给看盘的人；后半给改软件的人（网址、路径、坑）。

---

## 1. 先用一句话说清楚

麦蕊像一家「卖股市数字的店」。我们这套软件是本机助手：自选、一张分析表、白话问答、监控提醒。店里有的，软件才可能显示；店里没有的，软件不能编。

**表上的现价、涨跌、市值、财务、股东、分红，店里都有。**  
**「底、顶、离底%、目标卖价」店里不直接卖，要用每天的高低价自己算。** 算它们需要的「每天一根棒」是有的；能不能算到十几年前，要实测日线到底有多长，不能想当然。

**2026 年 9 月对照官网后：店里比两个月前那份旧清单多了很多货。** 其中「某个指数里有哪些股票」我们已经接到「行情」入口；其它多数还在店里、没摆上工作台。

## 2. 软件现在已经在用的（打开就能对上的）

这些不是新货，是你现在查询表、问答、监控已经在吃的：

| 你在软件里看到的 | 人话 |
|---|---|
| 最新价、涨跌幅、市盈率、市净率、换手、市值 | 这只股票此刻贵不贵、成交活不活 |
| 60 日涨幅、今年以来涨幅 | 近两个月、今年到今天走了多少 |
| 行业、主营、七大板块 | 它是干什么的 |
| 前十大股东、流通股东、总股本 / 流通股本 | 谁拿得多、盘子多大 |
| 每股净资产、每股收益、研发费用、毛利率 / 净利率 | 报表上薄薄一层 |
| 资金流入、流出、净流入 | 当天大单进出的一个汇总，**不是北向** |
| 近 1 年底、更长的底和顶、离底%、目标卖价 | **软件用日线自己算的**，不是店里现成一列 |
| 分红 / 增发 / 解禁 | 监控「公司事件」在盯有没有变化 |
| 沪市全部、深市全部、北交所全部 | 各交易所挂牌名单 |
| **上证指数、深证成指、北证50、上证50、中证500、创业板指的成份股** | **这次已接通**：按指数名单查/导，不是把整个交易所冒充成指数 |

科创综指店里的「指数树」没有这一支，软件不会拿科创50或科创板全部来凑。北交所财务、股东常常空，以前文档也说过京市能力弱；官网后来补了京市报表和日线，**软件查询表还没改接**，所以格子仍可能空。

## 3. 这次对照官网后，新确认「店里有、可以去取」的

相对 2026-09-02 那份约 74 条旧清单，以及当时「指数成份不知道有没有正式接口」的判断，下面这些是**新确认有货**的。有的我们已经接了，多数还没摆上表。

### 3.1 已经接到软件里的新增

| 新确认的内容 | 人话 | 软件里现在怎样 |
|---|---|---|
| 指数成份名单 | 「上证指数里到底有哪些股票」有官方名单，不是猜路径 | 「行情」选指数，查/导只含成份股。现网已跑通上证约两千只、深成指 500、北证50 等 |

### 3.2 店里有、查询表还没当成正式列的（hsdata 沪深基础）

| 新能查到的 | 人话 | 现在软件 |
|---|---|---|
| 问董秘 | 投资者问公司、公司书面答复 | 没有入口 |
| 交易所公告列表 | 这家公司发过哪些公告标题 | 监控事件主要靠分红/增发/解禁摘要 + 巨潮链接，**没有公告分类** |
| 涨跌停当天表现 | 这只票今天怎么封的、封了多久一类盘后数字 | 没有涨停/跌停提醒任务 |
| 集合竞价表现 | 开盘前那几分钟怎么定价 | 没有 |
| 订单流（按日、盘后） | 更细的买卖力量切片 | 资金列只有汇总流入流出 |
| 指定某一天的逐笔成交 | 那天每一笔（有起始日期限制） | 没有给用户点选 |
| 指定某一天的资金流向 | 那天大单进出，不必只看「最新这一档」 | 资金列偏当天 |
| 交易日历 | 哪天开市、哪天休市 | 指定某日收盘价还没做；休市回退也没做成功能 |
| 券商的板块树、板块里有哪些股 | 比「名字里带两个字就算这个概念」更接近官方篮子 | 概念筛选仍是关键词，不是官方成分 |
| 1 分钟很细的走势 | 要更高档套餐（Quant Pro / 企业版） | 位置计算用日线，不用 1 分钟 |

### 3.3 分析中心另开的货架（hanalyse）

这些在「沪深分析 / 数据中心」那一摊，**不是**基础行情页同一套：

| 新能查到的 | 人话 | 注意 |
|---|---|---|
| 龙虎榜、今日交易提示 | 谁在席位上买得凶 | 软件监控没有龙虎榜任务 |
| 融资融券、大宗交易 | 借钱做、私下大宗 | 未接 |
| 机构持股（分析口径） | 和自选表上的「十大股东」不是同一张表 | 监控有「活跃资金持股」，吃的是基金持股那路 |
| 板块资金、个股资金排名、资金路线图 | 今天钱往哪个行业涌 | 未做成列或芯片 |
| 南北向资金（沪股通、深股通这类） | **全市场或大盘一条线**，不是「你自选每一只、每一个交易日」 | 表上「北向」列现在是空的，**这一摊仍然补不满那一列** |
| 可转债 | 另一类品种 | 软件不做转债池 |

### 3.4 其它市场文档变厚了

| 市场 | 以前旧清单给人的印象 | 现在官网写了什么 | 软件 |
|---|---|---|---|
| 北交所 | 几乎只有名单和现价 | 日线、报表、股东也可以查（要实测真假） | 表上北交所财务/股东常空 |
| 科创板 | 好像要单独再拉一份名单 | 沪深股票名单里已经含 688 | 沪市全部已含科创；K 线跟沪深同一套更稳 |
| 基金 / ETF | 另有文档 | 净值和档案在 | 本软件不做基金池 |
| 指数点位 | 一直有 | 仍是点位和 K 线，**不含成份股** | 顶栏上证/深成/科创点位；成份走上面 3.1 |

### 3.5 店里仍然没有、不要指望这次更新

| 你可能想要的 | 为什么没有 |
|---|---|
| 随便搜全网新闻、彭博快讯 | 麦蕊不卖新闻检索 |
| 原油、铜、股指期货的实时价格 | 没有品种行情，只有「这只股票名字上像哪个品种」 |
| 出口占收入多少 | 没有；软件只认你自己放的一张表 |
| 并购、回购的起止日结构化字段 | 公告列表没有这种分类标签 |

## 4. 这些新货，可以拿来完善软件的哪一块？

按「对你已经在用的功能最有帮助」排序。括号里是欠账编号，方便以后对表，不是开工令。

### 4.1 马上对得上、收益最大

**1）概念 / 板块筛选（欠账 U7）**  
现在点「2026 概念」是拿关键词去碰文字，会漏、会误伤。店里有「概念代码 → 成分股名单」，和指数成份是同一类取法。接上之后，筛选可以变成「官方篮子里的股票」，和「行情按指数导出」同一套规矩。

**2）涨停 / 跌停提醒（欠账 U15）**  
店里有涨停池、跌停池，还有单只股票当天涨跌停表现。可以做成：自选或关注池里有人涨停/跌停 → 进监控「今日」。这比现在只有资金异常、离底、减仓更靠近盘中情绪。

**3）指定某日收盘价（欠账 U14）**  
旧表有一列「填一个日期，看那天收在哪」。原料就是日线，交易日历能告诉你那天开不开市。软件已经在用日线算底和顶，**多一个日期框就能复用同一份缓存**，不必再买新种类的数据。

**4）3 日 / 5 日 / 10 日涨幅（欠账 U13）**  
表上已有 60 日、今年以来。店里有现成的短周期涨幅和换手，不必自己从日线加总。适合加进「列设置」里默认不勾、需要再打开。

**5）北交所空格子**  
若京市日线和报表实测能通，北交所那几只就不必整列空着。这是补现有表，不是新功能。

### 4.2 能加强「监控」和「问答」，但要克制范围

**6）公告 + 问董秘**  
监控现在只能发现「分红/增发/解禁摘要变了」。接上公告列表，问答可以引用「最近发了什么标题 + 链接」，不必假装有全网新闻（新闻仍然没有）。并购回购若只要「有没有公告」可以部分缓解；若要起止日结构化，公告接口仍然不够（欠账 U8）。

**7）订单流、按日逐笔、按日资金**  
可以把「资金异常」从「相对近几天均值」做成「指定某日、分大单小单」。问答可以回答「昨天主买多还是主卖多」。会多耗次数，适合只打自选，不要打全市场。

**8）集合竞价、涨跌停表现**  
适合盘后复盘和「今日」里多一条「开盘定价异常 / 封板质量」，不要做成荐股。

**9）龙虎榜、机构席位、板块资金**  
适合 researcher「看市场」多一段「今天钱去了哪、席位上有谁」，以及监控里一条可选的「自选上榜」。不要做成全市场选股器。

**10）交易日历**  
指定日收盘、监控「只在交易日跑」、墙钟档口跳过周末，都用得上。

### 4.3 接了也解决不了、或性价比低

**11）南北向全市场序列**  
补不满「自选每一只、每一个交易日的北向」。要么对客继续写「这一列空着」，要么改口径成「只看大盘北向」，不要把全市场曲线贴到每只股票上充数（欠账 U5）。

**12）1 分钟 K 线**  
要更高档套餐，对「离底、目标卖价」这种日线逻辑帮助不大。除非以后做盘中秒级盯盘，否则先不做。

**13）可转债、基金档案**  
和当前「A 股自选助手」不是同一条产品线，默认不接。

**14）期货价格、出口占比、全网资讯**  
这次官网更新**没有**补上。监控灰卡、问答「问了也是没有」应保持，不要用相关股票名单假装有期货价。

## 5. 必须自己算、或永远算不准的

| 表上的想法 | 店里 | 怎么办 |
|---|---|---|
| 近 1 年底、十几年底、顶 | 没有现成一列 | 用每天最高最低自己找；「十几年」取决于日线有多长 |
| 离底%、顶底倍数、底再涨一半当卖价 | 没有 | 现价加上面算出来的底 |
| 某日收盘（X 日价） | 没有单独一列，但日线里有那天 | 填日期去日线里取；休市或停牌要往前找最近开市日 |
| 补贴收入 | 有旧字段，近年报表常空 | 会计准则改了，多数要看「其他收益」 |

**日线到底能回到哪一年：** 文档只说「不选日期就是全部历史」，没保证回到上市那天。中直若要从 1997 年算「长窗底」，必须用正式证书实测第一根棒的日期。演示证书会假装所有股票都是同一份样本，测了也作不得数。

## 6. 使用上只要记住这几条

1. **证书有当日次数。** 全市场现价那种「一次拉全部」官方写明大约一分钟只能一次。自选几十只通常够用；把指数两千只当「刷新全表」会很快打满。打满后格子会空，不是软件把假数填上。
2. **演示证书不能当实盘。** 它不理你查哪只股票，只给固定样本。软件会挡住，避免你把样本当成全市场。
3. **指数成份 ≠ 该交易所全部。** 深证成指不是深市全部；北证50 不是北交所全部。
4. **北向、新闻、期货价、出口占比** 不要指望靠这次「官网变多了」自动出现。
5. **数字以麦蕊当天为准。** 底和顶是软件算法，换复权方式整张表都会变；现在跟旧表一样按不复权算。

## 7. 给改软件的人：路径、已接、坑

调用基址：`https://api.mairuiapi.com`。图 1 仍缺的源（新闻、期货 K 线、出口、个股每日北向）见 [`../问题/P-20260915-麦蕊数据源缺口.md`](../问题/P-20260915-麦蕊数据源缺口.md)。

### 7.1 已接线（查询表 / 池 / 监控主路径）

| 用途 | 路径要点 |
|---|---|
| 名单（含科创 688） | `hslt/list`；北交所 `bj/list/all` |
| 现价（自选批量） | `hsrl/ssjy_more`，最多 20 只；单只 `hsrl/ssjy/{6位}` |
| 指数点位 | `hsindex/real/time` 或 `hsindex/latest` |
| **指数成份** | `hszg/list` 取 `type2=7` 叶子，再 `hszg/gg/zhishu_{6位}`。不要用 `hsindex/constituent`（404） |
| 日线（底顶原料） | `hsstock/history/{code}.{市场}/d/n` |
| 简介 / 分红增发解禁 | `hscp/gsjj` `jnfh` `jnzf` `jjxs` |
| 股东 | 优先 `hsstock/financial/topholder` `flowholder` `capital`；备用 `hscp/sdgd` |
| 财务薄层 | `pershareindex` + `income`（`yffy`、`btsr` 空则 `qtsy`） |
| 资金流向 | `hsstock/history/transaction/{6位}`（注意只要 6 位） |
| 涨停等股池（数据有，监控任务未做） | `hslt/ztgc` `dtgc` 等 |

pytest 强制离线；现网 `MAIRUI_OFFLINE=0`。成份探针：`scripts/Verify-Index.ps1`。

### 7.2 官网已公开、仓库未当查询列

`hsstock/interactiveqa`、`announcement`、`lup/limit`、`lup/auction`、`orderflow`；按日 `hsrl/zbjy/{yyyyMMdd}`、`hsstock/history/transaction/{yyyyMMdd}`；`tcalendar/list/{年}`；`hslt/sectorslist` `primarylist` `sectors/{名}`；Quant Pro 1m：`hsstock/pro/*`。

hanalyse 南北向：`/ht/nbzj/*`，**禁止**用 `history/transaction` 冒充北向。

概念官方成分：与指数相同，`hszg/gg/{树节点 code}`（如申万 `sw_*`、概念节点），不要只做关键词。

### 7.3 坑（仍有效）

| 编号 | 要点 |
|---|---|
| 历史深度 | 标准 `history` 未承诺上市以来；「日线上市以后全部」只写在企业版 vip。正式证跑 `Verify-Api.ps1` T3+T4 |
| 代码格式 | `hslt/list` 的 `dm` **已带** `.SZ`；`hsrl`/`hscp` 要 6 位。`hsstock/history/transaction` 在 history 路径下却只要 6 位 |
| 演示证 | 忽略代码，固定样本；门禁不得当全市场 |
| 全市场现价 | `hsrl/ssjy/all`、`hsrl/real/all`：**1 分钟 1 次**，包年/钻石或 Quant Pro |
| 空值 | 财务常见字符串 `"-"`，不是 JSON null |
| `hscp/sdgd` | 内层字段可能首字母大写 |
| 文档笔误 | 模板写 `/证书{licence}` 是错的；指数演示有时写成 `000001.SZ` |
| 限频栏 | 多数接口频率数字是同一套模板；以「说明」为准 |
| 北交所 | 不在 `hslt/list`；`bj/history` 文档有、代码未接未测 |

指数树实测（正式证，2026-09-21）：`zhishu_000001` 2228；`399001` 500；`899050` 50；`000016` 50；`000905` 500；`399006` 100；`000688` 科创50 共 50；**无 `zhishu_000680` 科创综指**。

### 7.4 落地顺序（未变）

0. 正式证跑通日线深度（决定长窗底能不能信）。  
1. 名单落库；6 位 / 带后缀按接口选。  
2. 日线缓存，本地算底顶离底目标卖价。  
3. 现价刷新。  
4. 财务、分红、股东。  
5. X 日价走日线缓存。  
6. **新：指数/概念一律 `hszg/gg`；公告问董秘涨停池按自选接，不要先接全市场。**

条数字段仍以官网各页为准。本文不是麦蕊全站清单。
