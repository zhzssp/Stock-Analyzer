# 对客功能说明

> 按当前方案（[`设计文档.md`](./设计文档.md)）做完后，用户能直接用到什么。
> 本文只讲「看见什么、能做什么」，不讲内部怎么拆智能体。
> 撰写日期：2026-09-11

---

## 一句话

用户面对的是一套**自选股助手**：一张看得懂的分析表、可以问数的对话，以及不用盯盘也会把「该看的票」推过来的提醒。系统**不代替下单，也不保证赚钱**。

默认只看你的自选池（大约现有表里那几十只），不是全市场选股器。

---

## 用户能用的三件事

### 1. 自选分析表

打开就能看到和现有炒股表同一套口径，按行是一只股票：

| 用户看到的 | 用来干什么 |
|---|---|
| 代码、名称、现价、涨跌、换手、总/流通市值、PE、市净率 | 扫一眼盘面 |
| 近 1 年底、17 年后底、顶、离底%、高底倍数 | 判断现在在历史区间的什么位置 |
| 目标卖价（默认「底涨 50%」）、比价差% | 判断离自己的减仓位还有多远 |
| 指定某一天的收盘价（X 日价） | 和某个自己记得的日子比 |
| 净资/股、每股未分配利润、营业总收入、研发费用、其他收益 | 看基本面薄薄一层 |
| 近年每 10 股派了多少息 | 看分红习惯 |

自选可以加减、分组（自选 / 观察 / 备选）。某列暂时没数据时会空着或标明「数据不足」，不会整张表挂掉。

底、顶、目标卖价的算法可以改（比如窗口不是 17 年、目标不是涨 50%），改完表上的数跟着变。

### 2. 问答

对着池子里的股票用白话问，例如：

- 中直现在多少、涨了没？
- 离底部还有多远、目标卖价是多少？
- 2026-03-05 那天收在哪？
- 净资和研发费用呢？
- 今天为什么推了这只？（盯盘推送之后）

答的是表上已经算好的数和事先定好的口径。没有的数据会直说没有，不会编。

### 3. 盯盘提醒（不用一直开着表）

交易时段系统自己刷新行情；每个交易日晚上再算一遍底部和目标价，出一份日报。

事先写好的规则命中时，把「值得看」的票推出来，并附上一句人能读的理由，例如：

- 回落到接近历史底部（默认离底约 8% 以内）
- 现价已经靠近目标卖价，可以考虑减
- 相对你指定的那一天，涨跌超过一定幅度
- （后续）自选里有股票进了涨停池

同一条提醒不会一天刷好几遍；一轮最多推有限几条，避免刷屏。没有命中时，日报也可以说「今日无」。

第一版推送先落到本地记录；以后再接到桌面通知、微信等。用户看到的始终是：**哪只、因为哪条规则、当时的关键数字**。

## 稍后会补上、但方案里已经预留的

这些不是第一眼就能用到的，打开对应能力后才会出现在表、问答或提醒里：

- 十大股东 / 十大流通股东、股本结构、户数变化
- 业绩预告、解禁日程
- 自选是否出现在涨停/跌停/炸板名单里
- 资金流向、常见技术指标、所属概念

---

## 用户不会看到的（刻意不做）

- 自动买卖、接券商下单
- 「推荐你买这只、能赚多少」这类承诺
- 默认全市场海选
- 没有数据时用模型编出来的数字

推送的是「规则命中」，不是投资建议。看完之后买不买，仍由用户自己决定。

---

## 一天里大概怎样用

| 时候 | 用户侧 |
|---|---|
| 盘中想扫一眼 | 打开表，或问一句现价 / 离底 |
| 盘中没盯盘 | 接近底部或接近目标卖价时收到提醒 |
| 晚上 | 收到当日摘要：命中了谁、为什么 |
| 想核对某天价格或财务 | 问，或在表上看对应列 |

两块可以分开用：只看表、只开提醒、或两个都开。
