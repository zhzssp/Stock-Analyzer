## 0. 怎么读本文

| 档 | 含义 | 能否靠「补一个按钮」完成 |
|----|------|-------------------------|
| **占位** | 注册表/监控/Tool 有名字，`enabled=0` 或恒空，**故意不跑** | 否，要先有源或改产品承诺 |
| **半成品** | 主路径在用，但数据、参数、状态机缺一块 | 部分可以（如 Webhook 表单）；部分要先接源 |
| **API 未产品化** | `MarketClient` 或 Tool 已能调麦蕊，**查询列/监控/工作台未接** | 是，属产品扩展 |
| **工程未收尾** | 行为可用，但额度/体验/暴露不完整 | 是，属实现优化 |
| **分期/环境** | 设计写了 S0/S9 或正式证实测 | 依赖 licence / 产品决策 |

**不登记：** 自动买卖、荐股、全市场选股器、没数时编数（故意不做）。
