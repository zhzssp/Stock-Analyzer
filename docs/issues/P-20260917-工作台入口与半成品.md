## 3. C：半成品（有壳，不能当已完成）

补入口也变不成「已落地」，除非先补参数、数据或打开插槽。

### C1 自选 / 观察 / 备选分组

- `watchlist.group_name` 列存在；`GET /watchlist` 会回 `group`。
- `PUT` / `POST` 写入时 **写死** `group_name="自选"`。`WatchIn` 没有分组字段。
- 前端没有分组 UI。对客已写「现在没有」。

### C2 北向资金列恒空

- 字段 `northbound` 已注册，列设置里能勾。
- `QueryEngine.run` 写死 `"northbound": None`。
- 个股日频北向盖不住：P-20260915 §2.1。不能靠前端「显示这一列」假装有数。

### C3 期货 / 资讯 / 政策监控关着

- `watcher.JOBS` 有 `futures` / `news` / `policy`，`enabled=0`，带 `reason`。
- 前端列表会画出这三项，开关因 `reason` 开不了（`toggle` 会 409）。
- Tool 插槽 `futures_quote`、`web_finance_search`、`policy_news` 均为 `enabled: false`。
- 无源判定：P-20260915 §1。

### C4 提醒通道 Webhook

- `GET /health` 的 `channels` 含 webhook；`src/platform/channels.py` 在配置了 `ALERT_WEBHOOK` 时 POST。
- 只认 `.env`，工作台不能配、也看不到（叠 A9）。
- 对客写明：没有手机 / 微信推送。

### C5 盯盘快照不对用户开放

- 表 `snapshots` 存在；`watcher` 用它做股东 / 资金差分。
- 没有列出 / 导出 snapshot 的 API，工作台也没有「今早对照」。

### C6 没有退出登录

- 无 logout API（token 无状态）。
- 前端只在 401 时清 `sa_token`。顶栏没有「退出」。

### C7 出口占比 Tool 开着但默认无表

- `export_share.yaml` 为 `enabled: true`，无 csv 就空。
- 与 B5 同一条能力：对客「现在没有」仍然成立，直到有手工表或第二数据源。
