# P-20260924 北证50 指数点位无源（只拿得到成份，拿不到点位）

> **状态：开放（已核实，等第二数据源）**
> 核实日期：2026-09-24（正式 licence，内置证 `2FE37018…`）
> 方法：直接打麦蕊接口实测 + 拉官方《沪深主要指数列表》比对，不是只看文档
> 相关：[API现状](../API/API现状.md) §3.1 / §7（额度）、[对客功能说明](../usage/对客功能说明.md)、[R-20260921 欠账表](../requirements/R-20260921-未完成能力欠账.md)
> 代码：`src/market/indices.py` `BOARD_INDICES`、`src/market/client.py` `_index_board_item` / `_index_quote`

一句话：**麦蕊知道「北证50 由哪 50 只股票组成」，但不知道「北证50 现在多少点」。** 这两件事是两条不同接口，不要混为一谈。

---

## 0. 结论

| 想要的东西 | 接口 | 结果 |
|---|---|---|
| 北证50 **实时点位 / 涨跌幅** | `hsindex/real/time/{code}`、`hsindex/latest/{code}`（栏目 hszsdata「沪深指数数据」） | **无源**（见 §1） |
| 北证50 **成份股名单** | `hszg/list` → 树节点 `zhishu_899050` → `hszg/gg/zhishu_899050`（栏目 hsdata） | **有**，50 只，2026-09-21 正式证实测已落 `data/index_probe.json` |

所以抬头那一格**不能显示点位**——显示就是编数。当前改成显示官方成份数量（50 只），并可点进该指数池。

## 2. 为什么又能说「走官方成份数据」

因为成份名单走的是**另一条接口**，与点位无关：

- `src/market/indices.py`：`index_tree_code()` → `zhishu_899050` → `constituent_paths()` = `/hszg/gg/zhishu_899050`
- `data/index_probe.json`（2026-09-21 正式证探针）：
  `899050.BJ` → `enabled: true`、`count: 50`、`source: /hszg/gg/zhishu_899050`

两者分属麦蕊不同栏目：

| 栏目 | 文档入口 | 给的是什么 |
|---|---|---|
| hsdata（沪深基础数据） | https://www.mairuiapi.com/hsdata | 概念 / 指数**成份名单**、个股档案 |
| hszsdata（沪深指数数据） | https://www.mairuiapi.com/hszsdata | 指数**点位与 K 线**，说明里写明「沪深两市」，`jys` 仅 sh / sz |

## 3. 软件现在怎么处理（不是临时绕过）

- `BOARD_INDICES` 每条带 `kind`：`quote`（有点位，走 hsindex）与 `pool`（无点位源）。
- 北证50 是 `kind: pool`：`src/market/client.py::_index_board_item` 只读 `index_status()`（本地官方成份数），**一个请求都不打**，返回 `p=None`。
- 前端 `docs/frontend/index.html::renderBoard`：`pool` 类型渲染成「北证：50只」，带 `data-pool="index:899050.BJ"`，点一下调 `selectPool` 进该指数池；tooltip 写明原因。
- 抬头点位另有 60 秒 TTL 缓存（`settings.board_quote_ttl_sec`），与这条无关，见 `API现状` §7。

相关测试：`tests/test_api_offline.py::test_board_indices_offline`（断言北证 `p is None` + 成份数）。

## 4. 关闭条件（二选一）

1. **有第二数据源**：能提供北证50（或北证系列指数）的实时点位与涨跌幅 → 接进来，`kind` 改回 `quote`，抬头显示真正的点位，并在 `API现状` 登记新源。
2. **明确保持现状**：对客说明已写「北证栏显示成份数量，不提供实时点位」，本条转为「已知无源、不做」，状态改为关闭并写明理由。

**不做的事（关闭前都不要做）：**

- 不要用 50 只成份股自己算一个「北证50 点位 / 等权涨跌」——那是自造指数，属于编数；
- 不要拿北交所全部挂牌或某一只成份股代替；
- 不要把 `hsindex` 对北证的 404/422 当「接口偶发故障」重试，目录里确实没有。
