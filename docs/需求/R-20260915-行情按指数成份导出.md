# R-20260915 行情按指数成份导出

> 状态：**已落地（离线切片）**。正式 licence 下的完整官方成份仍等 S0 探针证实接口后替换切片。
> 提出：2026-09-15
> 来源：用户对照 [对客功能说明](../使用/对客功能说明.md)「登录和自选」中「行情 / 按交易所看一批股票」一条

---

## 原话

「行情」对应的是「上证指数」「深证成指」「北证」等，它们是由成份股组成，选对应行情应该只能导出对应的成份股，不能分别将深沪北三个交易所所有股票导出来。

配图圈中的是当时对客说明里的句子：侧边改看「行情」后按交易所看一批股票，导出的是当前正在看的这一批。

---

## 口径（已对齐）

| 用户说的「行情」 | 池 id | 导出范围 | 禁止当成 |
|---|---|---|---|
| 上证指数 | `index:000001.SH` | 该指数成份股 | 沪市全部 `exchange:sh` |
| 深证成指 | `index:399001.SZ` | 该指数成份股 | 深市全部 `exchange:sz` |
| 北证 | `index:899050.BJ`（北证50） | 该指数成份股 | 北交所全部 `exchange:bj` |

查询和「导出 Excel」必须跟当前选中的指数池，表头仍是图 1。

交易所全市场（`exchange:*` / `board:*`）可以留在 API 里给调试/大池任务用，**不得再作为「行情」侧栏的默认入口**，也不得用指数名字去标全市场名单。

---

## 验收

1. 工作台点「行情」，芯片是上证指数 / 深证成指 / 北证50 等指数名，默认选中一个**已启用的指数**。
2. 选深证成指后查询、导出，名单不得等于深市全部；选北证50 不得等于北交所全部；选上证指数不得含深市、北交所代码。
3. 导出文件名或池名带指数名（例如「深证成指」），不得写成「深市全部」。
4. 不得把 `hslt/list` 按交易所切片贴上「上证指数」等名字。
5. 离线模式允许用**小于全市场的成份切片**跑通界面；切片须标明不是完整官方成份。演示 licence 的实盘导出仍拒绝。

---

## 方案

1. **数据：** `fixtures.INDEX_CONSTITUENTS` 为离线成份切片（有意小于对应交易所离线全集，用来证伪「全市场冒充成份」）。`index_status` 在离线/无 licence 时按切片 `enabled=true`；有正式探针结果时优先用探针代码。
2. **解析：** `list_index` / `resolve_pool("index:…")` 只返回成份列表。
3. **界面：** 「行情」只渲染 `kind=index` 芯片；点「行情」选第一个已启用指数。侧栏提示写清「只导出成份股」。
4. **对客：** 改正文，去掉「按交易所导出」和「指数成份现在不能用」。

未做：全市场反扫 `hscp/sszs`；未证实的麦蕊「指数→成份」路径不当成已有。
