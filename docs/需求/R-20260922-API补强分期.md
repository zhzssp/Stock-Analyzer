## 一期（本批）

### 1. 官方概念成分（U7）

- `src/market/hszg.py`：`hszg/list` 匹配概念叶子 → `hszg/gg/{code}` 取成分。
- `GET /markets/instruments?concept=人工智能`：官方篮子 ∩ 关键词（无树节点时回退关键词）。
- 筛选弹窗点 2026 概念芯片时带 `concept=`。

### 2. 涨停 / 跌停监控（U15）

- 数据：`hslt/ztgc/{yyyy-MM-dd}`、`hslt/dtgc/{yyyy-MM-dd}`。
- 模板任务 `limit-up` / `limit-down`，默认开启、盘中 schedule。

### 3. X 日价（U14）

- 列 `x_price`；查询体 `x_date`（`YYYY-MM-DD` 或 `YYYYMMDD`）。
- 从已有日线取 ≤ 指定日的最近一根收盘（休市向前找）。

### 4. 3/5/10 日涨幅（U13）

- 列 `pct3` `pct5` `pct10`；数据 `hsstock/indicators/{code}` 字段 `3d` `5d` `10d`。

### 5. 北交所财务 / 日线

- `bj/history/{code}.BJ/d/n`、`bj/financial/pershareindex` 等；离线切片补 430017 财务样例。

## 二期（已接）

1. **公告 / 问董秘** — `announcements` / `interactive_qa`；监控 `corp-disclosure`；Tool `corp_disclosure`；`corp_events` 附带公告条数。
2. **按日资金** — `capital_flow_on_date`；`capital-flow` 任务默认 `use_prev_day`；Tool 支持 `day=`。
3. **涨跌停 / 竞价复盘** — `limit_performance` / `auction`；监控 `limit-review`；Tool `limit_review`。
4. **龙虎榜 / 板块资金** — `hilh/mrxq`、`hibk/zjhhy|gnbk`；监控 `dragon-tiger`；researcher Tool `market_breadth`。
5. **交易日历** — `tcalendar/list/{年}`；`close_on_date` 向前找最近交易日；盘中监控非交易日跳过。

**二期未做（刻意克制）：** `hsstock/orderflow` 1 分钟订单流（耗次数、需另开按日聚合）；全市场板块资金选股器。
