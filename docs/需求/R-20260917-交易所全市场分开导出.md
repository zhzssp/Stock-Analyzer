# R-20260917 沪深北交易所全市场分开导出

> 状态：**已落地（工作台入口）**。离线仍是切片，正式 licence 下才是 `hslt/list` / `bj/list/all` 全名单。
> 提出：2026-09-17
> 来源：用户确认「分别将深沪北三个交易所的全部股票导出来」是核心需求，要分开导出。

---

## 原话

当前的导出 Excel 表格是否可以分别将深沪北三个交易所的全部股票导出来？这是核心需求，要分开导出。UI 上需要给出这个入口，功能细节都要在前端体现出来。

与 [R-20260915](./R-20260915-行情按指数成份导出.md) 并存，不互相覆盖：

- 「行情」仍只导出指数成份，不得把上证指数写成沪市全部。
- 「交易所」才导出该交易所全部挂牌；沪、深、北各点一次，各下一张表。

---

## 口径

| 入口 | 池 id | 导出范围 | 禁止当成 |
|---|---|---|---|
| 交易所 · 沪市全部 | `exchange:sh` | 上交所挂牌（含科创） | 上证指数 |
| 交易所 · 深市全部 | `exchange:sz` | 深交所挂牌（含创业板） | 深证成指 |
| 交易所 · 北交所全部 | `exchange:bj` | 北交所挂牌 | 北证50 |
| 板块另池 | `board:cy` / `board:kc` | 创业板全部 / 科创板全部 | 创业板指 / 科创综指 |

一次导出只含当前选中的这一池。三所不得混在同一张 Excel。

---

## 验收

1. 工作台侧栏除「自选」「行情」外有「交易所」。
2. 芯片文案是「沪市全部 / 深市全部 / 北交所全部」，不是指数名。
3. 选深市后查询、导出，名单不得含沪市、北交所代码；文件名或池名带「深市全部」。
4. 工具栏能看到「当前导出：…」。
5. 离线模式标明切片；演示 licence 仍拒绝把样本写成全市场实盘。
