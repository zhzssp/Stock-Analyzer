# 对客功能说明

> 只写你现在打开软件能做什么、故意不做什么。分工见 [`../INDEX.md`](../INDEX.md)。
> 第一次安装请看 [本地部署教程](./本地部署教程.md)。
> 更新日期：2026-11-08

---

## 一句话

这是一套**本机自选助手**：管自己的股票池，看一张分析表，用白话问数，重要变化会记在提醒里。

**不帮你下单，也不保证赚钱。** 打开后默认看你的自选。需要时可以改看某一个交易所的全部挂牌，但沪、深、北是分开导出的，不会合成一张全市场总表。

---

## 先认路：界面地图

打开 `http://127.0.0.1:8765`，**先登录**再进工作台（默认账号见 [本地部署教程](./本地部署教程.md)）。登录本身不会向数据方再查一遍。点开一个池子时，如果本机已经有这份副本，就直接打开它，状态行会写出各只股票的取数时间；还没有副本时，只显示名单。

登录后屏幕分成四块：

| 区域 | 在哪 | 干什么 |
|---|---|---|
| **顶栏** | 最上面一行 | 左边是五个主要指数（点位或成份数），右边是你的登录状态 |
| **左侧栏** | 屏幕左边一列 | 选「看哪一批票」：**自选 / 行情 / 交易所**，以及添加自选、搜索、决策卡入口 |
| **主区四个页签** | 屏幕中间上方 | **传统查询**（分析表）、**Agent 问答**（白话问数）、**监控中心**（提醒与规则）、**本机数据**（占用、证书、存档） |
| **弹窗 / 抽屉** | 点按钮后浮出 | 登录、添加自选与筛选、列设置、导出选项、沪深全部、页码、档案库、添加规则、决策卡（右侧滑出） |

一句话走法：**先在左边选「看哪一批票」→ 中间点「查询」看表 → 需要就「导出 Excel」；两市都要更新就点「沪深全部」；想问话就去「Agent 问答」；想知道发生了什么变化去「监控中心」。**

### 第一次打开，照着做

1. 用浏览器打开上面的地址，登录。登录本身不会再向数据方查一遍。
2. 左侧停在「自选」。点「+ 添加 / 筛选」，搜名称或代码，点「加入自选」。
3. 中间默认就是「传统查询」。列不够或太多，点「列设置」。默认预设是「研究」。
4. 点「查询」。这一轮优先用本机已经有的数，缺的才去要。表出现之后，工具栏下面的状态行会写进度。
5. 盘中只想要新价格，点「刷新行情」，不要点「全量更新」。
6. 要留下文件，点「导出 Excel」，看一眼「当前导出」是不是这一批，再确认。
7. 深市和沪市都要更新时，点工具栏上的「沪深全部」，选全量更新或只刷新行情，再决定这一轮要不要导出。它先做深市，再做沪市，不会两市一起取。
8. 「全量更新」把勾选的列全部重新向数据方要，大池还要一页一页走完，**最费授权次数**。日常补表用「查询」。

进行中再点同一个按钮，会提示「这一轮还在进行」，不会叠着再开一轮。

## 顶栏那一行指数

显示 **上证 / 深成 / 北证 / 科创 / 创业**，每 20 秒左右更新一次。

- 上证 = 上证指数、深成 = 深证成指、科创 = 科创综指、创业 = 创业板指：显示**点位和涨跌幅**（红涨绿跌）。
- **北证** 一栏显示的是 **「50只」** 这样的数字，不是点位：数据方不提供北证50 的实时点位，所以这里只显示它的官方成份数量。**点一下「北证」，可以直接跳到北证50 这个指数池**（建议先切到左侧「行情」再点）。

## 左侧三个入口：决定「看哪一批票」

三个按钮在左侧栏最上方，同一时刻只有一个生效；查询和导出都跟着当前选中的这一个走。

### 自选（日常用这个）

- 只含你添加过的票。沪、深、北的票会在同一张表里。
- **怎么加票**：点「+ 添加 / 筛选」→ 弹窗里可以按市场（沪市 / 深市 / 科创 / 创业板 / 北交所）筛，也可以按**七大板块、申万一级行业、2026 概念**点选，或搜名称/代码。
  - 弹窗底部三个动作：**加入自选**（追加）、**替换自选**（先清空再写入，会二次确认）、**仅查询一次**（不改自选；这时导出也只含这一批）。
  - **2026 概念**：点它时先取该概念的**官方成份**；官方目录里没有这个概念的，才退回用关键词去对行业/概念文字——这时就不是官方成份了。
  - 还能自建**自定义概念**（名称 + 关键词，最多 16 个、每个最多 8 个关键词，不能和内置重名）：它只是**关键词匹配文字**，不是官方成份股，只在本机有效。
  - 添加进来的票，分组一律是「自选」；要改成「观察 / 备选」，去这只票的决策卡里改。
- 列表里：**点名称**打开右侧决策卡；**按住拖动**可改上下顺序（右侧表跟着这个顺序）；**右键**出菜单，可「打开决策卡」或「移出自选」；搜索框按名称或代码过滤。自选**全部展示**，不分页。

### 行情（指数成份）

- 列出指数芯片：**上证指数、深证成指、北证50、创业板指、中证500、上证50**（都是官方成份名单）。
- **上证指数 ≠ 沪市全部，深证成指 ≠ 深市全部，北证50 ≠ 北交所全部**，点芯片只查/导这一指数的成份股。
- 点芯片后会打开这个指数上次留下的副本；还没有副本时只显示成份名单，并按涨跌幅从高到低排。要新数字再点「查询」「刷新行情」或「全量更新」。
- 科创综指不在官方指数目录里，所以列表里没有它，也不会拿科创板全部来代替。
- 下面的成份列表**只用来看**：点列表里的股票不会有任何动作。想把它加进自选，请到「自选」页用「+ 添加 / 筛选」搜索。
- 成份多的时候，左侧列表一次显示 100 条，点末尾的**「显示更多」**继续。导出 Excel 写的是这个指数**已经打开的副本**，不是当场把全部成份再查一遍。副本里还没有的股票，格子是空的。

### 交易所（全市场）

- **沪市全部、深市全部、北交所全部**：一次只出一所，要三张表就点三次。沪市含科创，深市含创业板。
- 下面还有**板块另池**（创业板全部 / 科创板全部）：这是按板块标签筛出来的池，**不是**创业板指 / 科创综指，别混着看。创业板全部只含代码以 `300` 开头的股票，不含 `301`。
- 和「行情」一样，交易所与板块的列表**只用来看**，点里面的股票不会加进自选。
- **沪深全部**不在左侧，在分析表工具栏上。它只做深市全部和沪市全部，不含北交所。深市含创业板，沪市含科创，所以两市都做完之后，不必再把创业板全部、科创板全部各全量更新一遍。用法见下面「一次做完沪深两市」。

**打开较小的池，可以借用更大池里更新的数，并写进这一池自己的副本。** 例如深市全部已经查完，而且比创业板自己的副本新，这时打开创业板全部，会把深市里对应的股票写进创业板自己的副本。状态行会写成「取自深市全部的快照……，已写入这一池的副本」。之后导出 Excel 用的就是这份副本，不用为了同一批数字再向数据方要一遍。自选也可以这样借用。

就这几条：

- 一整份都查完的大池，必须把你现在打开的这一池里的股票**全部包含在内**，才会整批采用。深市全部能覆盖创业板全部。它覆盖不了同时含沪市股票的自选，这时不会拿深市把整份自选换掉。
- 还没查完的大池，只会填它已经查到、而且比这一池更晚的那些股票。
- 这一池自己更晚的格子保留。对方某一格是空的，不会把你已经有的数擦掉。这一池里对方没有的股票也留着。
- 再打开一次、没有更新的数时，不会再写一遍。
- 用日期框看以前某一天，只是查看，不会把那天的表写回今天的副本。

## 顶部全局搜索：找一只票，看详情，再决定加不加

「传统查询」页的**最上面**有一条搜索栏（不用先在左边选池）：

1. 输入企业名称或代码，按**回车**（或点「搜索」）。名称、代码、行业与概念关键词都能搜。
2. 下方列出匹配的公司（已在自选的会标「已在自选」）。点其中一条 → 弹出**这只票的详情**。
3. 详情里会列出：名称、代码、最新价、涨跌幅、市盈率、市净率、总市值、所属行业、所属概念、主营业务、前十大股东。读取优先用本机缓存，缺的才向数据方取，**只查这一只**。
4. 弹窗底部三个按钮：
   - **加入自选**：直接进你的自选池（已在自选时按钮变成「已在自选中」）
   - **单独查询**：按当前列设置向数据方取这一只，结果显示在中间列表。不改自选，也不覆盖自选那份副本。这时导出 Excel 只含这一只。
   - **关闭**

## 分析表：查询、刷新、导出

### 工具栏按钮（从上到下、从左到右）

| 按钮 | 干了什么 | 什么时候用 |
|---|---|---|
| **查询** | 按当前勾选的列取数。现价可以复用本机短时间档；行业、财务、股东这类没过期的用本机已有结果，缺的才去要。大池一次只取一页（100 只） | 日常补这一页 |
| **刷新行情** | 只更新已勾选的行情列：最新价、涨跌幅、市盈率（动）、市净率、换手率、总市值(亿)、流通市值(亿)、60日涨跌幅、年初至今涨幅、相对成本%、距买区%、距减仓区%。不重拉行业、财务、股东，也不重算 3/5/10 日涨跌和已经有数的离底% | 盘中等最新价 |
| **行情后导出** | 紧挨在「刷新行情」旁边。勾上之后会记住。只在刷新行情正常结束时写一份 Excel | 盘中等价后想自动留档 |
| **全量更新** | 当前勾选的列全部向数据方重取，不用本机已经存好的。大池按每页 100 只自动走完，不用再点「加载更多」 | 觉得整表都旧了；**这个最费授权次数，别反复点** |
| **全量后导出** | 紧挨在「全量更新」旁边。勾上之后会记住。查询、全量更新、单独查询、仅查询一次，在这一轮正常结束时各写一份 Excel | 取完整表后想自动留档 |
| **沪深全部** | 先做完深市全部，再做沪市全部。弹窗里选全量更新或只刷新行情。进行中按钮变成「停止沪深」 | 两市都要更新，又不想自己点两次 |
| **页码** | 全量更新或沪深全部走到有页可看时出现。点开弹窗，选已经取完的页 | 大池取到一半想看前面的页 |
| **导出 Excel** | 把当前打开的副本写成 Excel 并下载，**不再向数据方查询**。当前池子还可以改选最近三天里留下的日快照 | 要留档、要给 Agent 读 |
| **列设置** | 勾选要看哪些列，也可以选预设 | 想换视角 |
| **档案库** | 打开本机已导出的 Excel，可再下载、预览前几行，或勾两份对照某一列 | 找旧文件 |
| **日期** | 打开你在这一天留下的查询表。同一天有多张时，优先最晚的那张完整表 | 想看以前某一天留下的表 |

把鼠标放在「查询」「刷新行情」「全量更新」上，会按你**现在勾选的列**列出这一轮会动哪些列。

**打开池子不会自动补齐。** 有上次留下的副本就打开那一份；更大的池里有更新的数时，按上面「交易所」一节写进这一池自己的副本。还没有任何副本时，只显示名单。要新数字，再点「查询」「刷新行情」或「全量更新」。

**连点不会叠着再开一轮。** 上一轮还在进行时再点查询、刷新行情、全量更新或沪深全部，会提示「这一轮还在进行」。换一个池、改点查询、改点刷新行情，或用日期框打开某一天，都会停掉还没走完的全量更新。

**全量更新怎么一页一页看：**

1. 点下去之后不用再点「加载更多」。当前池按每页 100 只自动走完。
2. 第一页取完就显示出来。后面的页取完后，点「页码」再选。已经取完的页可以点；正在取的页标着「取数中」；还没轮到的页是灰的，点不了。
3. 你正在看的那一页，不会被后面刚取完的页换掉。点某一页只是换着看，不会重新向数据方要，也不会停掉还在进行的全量更新。
4. 这时点表头排序，只排正在看的这一页，状态行写「排序只排这一页」。
5. 某一页失败，或这一页没有取到股票时，已经取完的页还能看。状态行会写停在第几页、以及原因。这不是「没有新的股票」——那句只出现在「查询」手动加载下一页、下一页是空的时候。
6. 页数超过 100 页时会停住，并写「页数过多，已停在这里」。
7. 已经有页码时再点「刷新行情」，只更新**已经取到的那些页**的行情列，行业、股东、财务保持原样，并且停掉还没走完的全量更新。

**状态行里的续传，先看开头：**

| 你看到的 | 意思 |
|---|---|
| **正在续传 · ……** | 这一轮正在接着上次没做完的股票做 |
| **现在没有在续传 · ……** | 这一轮已经停了，只是记下还剩多少没取。它不是还在后台跑。刷新页面后这行会消失；下次再点同一个按钮，条件还符合时会从剩下的继续 |
| **续传已完成** | 上次没做完的已经补完 |

能接着做的条件：同一天、同一交易时段；现价不超过 90 分钟；也没有跨过开盘、午休、收盘这些边界。过了这些，再点会重新取。查询、导出、单独查询不走这套续传。

**日期框：**

1. 选一个日期，打开你在这一天留下的查询表。同一天有好几张时，优先最晚保存的那张完整表；都没取完，就打开最晚的那张未完成表，并写明已保存多少只。状态行会写出是哪一池。
2. 这一天没有表时，中间的表不动，状态行写「这一天没有可打开的查询表」。
3. 把日期清空，不会向数据方要数，只是去掉这句提示，表还留在屏幕上。
4. 接着点查询、刷新行情或全量更新，会先清空日期框，再按现在的池子取数。
5. 这只是查看，不会把那天的数字写回今天的副本。左侧会切到这张表所属的入口，并标出对应的池，「当前导出」也改成这一池。接下来若点查询，查的就是这个池，不是打开日期之前的那一个。

本机按「哪一天、哪一池」各留一份日快照，默认大约留最近用过的 30 份。很久没再打开、也没再写入的旧日子，会在新增一份时被清掉。同一天同一池再查一次，只覆盖这一天，不另占一份。导出弹窗里的「导出哪几天」只列**当前这个池子最近三天**，和日期框能打开的范围不是同一件事。

工具栏下面有一行只读状态：**当前导出**（自选 / 某个指数 / 某个交易所 / 筛选一次）和**这一轮的进度**。进行中的刷新会带剩余时间；还没有完成过一只时显示「正在估算剩余时间」。打开副本时，状态行会写出这份副本里最早到最晚的取数时间。导出前瞄一眼「当前导出」，能避免导错一批。

### 一次做完沪深两市

点工具栏「沪深全部」，先看弹窗，再点「开始」。

1. **刷新方式**二选一：全量更新，或只刷新行情。全量更新按当前列重新向数据方要，每页 100 只。只刷新行情也按每页 100 只走完，但只动行情列，行业、股东、财务保持原样。
2. **按所选方式，每一市结束后导出 Excel** 跟着上面的选择走。选全量更新时，它就是「全量后导出」；选只刷新行情时，它就是「行情后导出」。在这里改勾选，会记到对应的那个开关上。切换刷新方式只是换着看另一个开关，不会把两个开关写成同一个值。
3. 点「开始」时记下这一下的选择。进行中再改勾选，只影响下一轮。两市都用开始时记下的那一个。
4. 顺序固定：先深市全部，再沪市全部。两市不会同时取数。深市含创业板，沪市含科创。不含北交所。
5. 进行中，按钮文字变成「停止沪深」。再点它就停。停在深市时，状态行写「沪深全部已停下，沪市还没开始」。
6. 某一页失败时，这一市已经取完的页还能从「页码」打开，沪市不会开始。状态行仍写停在第几页。
7. 导出开关开着时，每一市正常结束后立刻写一份 Excel，再开始下一市。导出没写成，下一市不开始，状态行写「已刷新，导出没有完成」。
8. 两市都正常结束时，状态行写「沪深全部 · 两市都已完成」。

中途停下、失败、或被新的一轮取代，都不导出。导出用的是当时屏幕上的列和已经打开的副本，不会为了导出再查一遍。

### 表里有哪些列（列设置里勾选）

- **基础**：名称、代码
- **行情**：最新价、涨跌幅、市盈率（动）、市净率、**60日涨跌幅**、**年初至今涨幅**、**3日涨跌幅 / 5日涨跌幅 / 10日涨跌幅**、**换手率**、**总市值(亿)**、**流通市值(亿)**（加粗项默认不勾，需要自己在列设置里打开）
- **公司**：所属行业、七大板块、申万一级、2026概念、所属概念/板块、主营业务/经营范围
- **股东**：前十大股东、前十大流通股东
- **财务**：总股本(亿)、流通股本(亿)、每股净资产、每股收益、每股未分配利润、研发费用、毛利率、净利率

预设三种：

- **看盘**：名称、代码、最新价、涨跌幅、市盈率（动）、市净率。
- **研究**（默认）：看盘那六列，再加所属行业、所属概念/板块、主营业务/经营范围、前十大流通股东、总股本(亿)、流通股本(亿)、每股未分配利润、每股净资产、每股收益、毛利率、净利率。不含资金流和底顶。

### 排序和列宽

- **默认顺序**：自选按左侧列表的上下顺序；指数成份和交易所名单打开后按涨跌幅从高到低排。
- 点表头的**「代码」或「涨跌幅」**可切换正序/反序（只有这两列能排序）。排的是**当前这一页**，或者已经加载出来的这些行，不会把还没打开的页一起排。
- 列宽可以直接拖，会记住。
- 没有数的格子在屏幕上显示「—」。写进 Excel 时这些格子留空，不写成破折号。

## Agent 问答（用白话问数）

页签：**Agent 问答**。

- 输入框直接说话，Ctrl+Enter 发送。例如：现在什么价、离底部多远、十大股东是谁、有没有分红增发解禁、研发费用和净利率怎么样、属于哪个板块、基金持股里有没有我们盯着的机构。
- **公告、问董秘、资讯、新闻、政策、龙虎榜，只有话里点到这些词才会去查。** 没点到，就不会为了它们再花一次额度。资讯和政策还要先在「监控中心 → 偏好」里填检索源；没填时，问答会直接说还没配检索源，不会编内容。
- 可以**从 Excel 复制一段表格粘贴进来**，或点附件按钮上传 `.xlsx / .csv / .tsv`，按表里的代码来问。
- **「看市场」**按钮：问今天自选盘面怎么样（走另一个策略，会自动带上今日命中与队列）。它不会顺带再查资讯、政策或龙虎榜；要查这些，在话里点名。
- 问关联期货时，回答给出品种名字，不给期货价格。
- 右栏：**历史对话**（点回之前某一轮）、**本轮引用**（数字来自哪个接口）、**Tool 轨迹**（它调用了什么）、**本机仓库**（档案份数、缓存条数、自选只数、占用），以及**日线查询**——输入代码就能看本机缓存/切片里的日线。
- 没配 AI 模型 key 时也能用：按问题里的词选工具再拼答案，不会自由发挥。现价、股东、财务、离底、资金、分红增发解禁、公告、资讯、政策、龙虎榜都在这批词里。墙钟档案和涨跌停复盘明细要配了模型才会被选到。
- 本轮问答可以点**导出**存成 Excel。
- 同一轮会记住你刚问过的股票；想换话题点「新对话」。

**能问什么、不能问什么**：它只引用工具取回来的数字，不编；**不荐股、不给目标收益和胜率**；问到「该不该买/卖」时，它只会陈述现价相对你的买区/减仓区和你的规则，**不会给操作指令**。回答里如果出现明确的买卖措辞，末尾会多一行说明：这只是数据整理，不提供买卖建议。

## 监控中心（不用盯盘，让它记着）

页签：**监控中心**，里面四个子页：**今日 / 规则 / 复盘 / 偏好**。右上角有「立刻跑一轮」。

自动排程：交易日 **09:00–15:00 每 5 分钟**扫盘中规则，**20:20** 跑日终规则并给昨天的命中打次日标签。

### 今日

- **该看**：还没处理的提醒队列（要紧的排前面）。问答里点「看市场」读的是同一个队列。
- **提醒**：命中的具体条目——哪只票、因为什么、当时的关键数字。每条提醒有四个动作：**已看 / 再观察 / 逻辑仍在 / 作废**。

### 规则

**模板规则**（默认开启的这些）：

| 规则 | 什么时候跑 | 说什么 |
|---|---|---|
| 十大股东变动 | 日终 | 有增减；出现你关注的机构会单独点出来 |
| 活跃资金持股 | 日终 | 基金持股里出现你关注的机构 |
| 资金异常 | 日终 | 净流入明显大于近来均值（默认 2 倍） |
| 公司事件（分红/增发/解禁） | 日终 | 有变化，带公告链接 |
| 公告 / 问董秘 | 日终 | 有新增 |
| 涨跌停 / 竞价复盘 | 日终 | 盘后表现与集合竞价量 |
| 龙虎榜上榜 | 日终 | 自选上了当日龙虎榜 |
| **接近底部** | **盘中** | 现价离历史底部很近（默认 8% 内） |
| **接近减仓** | **盘中** | 现价靠近你填的减仓价；没填就用统计目标卖价 |
| **决策卡提醒** | 日终（填了日期就按日期） | 决策卡上填的提醒日期到了，当天提一次 |
| **涨停** | **盘中** | 自选出现在当日涨停池 |
| **跌停** | **盘中** | 自选出现在当日跌停池 |

每张规则卡可以：改参数（阈值、范围）、**只跑这条**、开关、保存；「规则定义 / 监控需求」两段文字默认收起，填了会当作问答守则。

**灰着的三条（现在点不开，是故意的）**：期货联动、资讯冲击、产业政策。后两条在你到「偏好」里填了检索源之后会自动解锁；期货那条没有可解锁的路径。

**我的规则**（自己加）：点「添加规则」→ 填名称、选指标、运算符（≤ ≥ =）和阈值、范围（全部自选 / 某个分组 / 某一只）、时机（日终或盘中）、严重度（观察 / 行动）。

- 也可以选「**相对决策卡**」，拿现价去比买区高/买区低/减仓价/成本。
- **不选指标、只写文字**也可以保存：这时它**不会自动扫描**，只作为问答守则。
- 支持「预览」：试跑一次看会不会命中，**不写进提醒**。
- 做不到的：自定义脚本、跨股票或跨列运算、多条件组合、分钟级扫描、时间窗口条件。

### 复盘

给昨天的命中打次日标签：**次日同向 / 次日反向 / 波动不足 / 不按涨跌 / 尚无次日收盘**（下一交易日收盘后才打）。这些标签**只是描述涨跌方向，不是买卖建议**，也不会自动关掉任何规则。可以点「立刻复盘」手动跑。

### 偏好

- **关注机构白名单**：26 家机构（主权基金、稳市资金、投行、基金、ETF）默认全勾，也可以自己加。它只是**对照用的名字表**，不是这些机构的持仓实况。
- **检索源**：你自己填的 http(s) 页面或 RSS（最多 20 条），日终只抓这些地址。资讯冲击看标题或正文里有没有自选名称、代码；产业政策用类型为「政策」的源，还可以命中较长的行业名。**不是全网搜索，不做摘要**，内网地址和本地文件会被拒绝。填了之后这两条规则才会解锁，**问答里也能检索这些源**（同一份名单，命中会带链接）。没填源的时候，问答会直接告诉你「还没配检索源」，不会编内容。同一篇已经提醒过的文章，隔天不会再进今日。
- **提醒通道**（只读）：本机日志、监控中心列表 **恒开**；**Webhook 需要在本机配置里填了地址才会开**，界面上现在不能填。
- **数据插槽**：① 关联期货品种——只有品种**名字**，**没有期货价格**；② 出口占比——查某只票的出口/海外收入占比，只认你上传的本机 csv（可在这页上传），**没有表就是空的**。

## 本机数据

页签：**本机数据**。

- **运行档位**（这一页最上面）：**按内存自动**（默认）、**完整（问答 + 盯盘）**、**轻量（只留查询）**。内存不超过 8GB 时，自动档会暂停问答和自动盯盘，传统查询、导出和墙钟还在。改完点「保存档位」。切回完整后，问答入口马上恢复；要让占用真正降下来，退出助手再打开一次。
- **存储占用**：`data/` 的路径与大小、行情缓存（默认上限约 300 MB，超了先删最久没用的日线）、导出 Excel（每人默认只留最近 20 份）、提醒日志、日线（每只默认最多 500 根，覆盖写）、查询表快照。按钮：**刷新占用**、**清空行情缓存**（只删可再拉的缓存）、**只留最近导出**。
- **证书池**：证书分两种——**每天会恢复的**（当天用完第二天还能用）和**用完就没的**（总次数有限，用完会从列表里去掉）。在对应那栏的输入框里粘贴证书串、点「追加」即可；每条证书后面可以删除。
- **怎么用这些证书**（两件事分开选）：
  - **自动换**（默认）：这张用完自动换下一张。下面还能选「优先用哪种」——先用每天会恢复的（默认）/ 只用每天会恢复的 / 只用完就没的。
  - **固定用这一张**：只用你选中的那张，**用完不会自动换**。选它时会写明这张属于哪种、用完会怎样：每天会恢复的那类当晚停下、第二天自动恢复；用完就没的那类用完会从列表去掉、需要重新添加。
  - 改完点「保存」立即生效。**固定某张之后那张一旦用尽，软件会停下来告诉你，不会偷偷换用别的证书。**
- **墙钟档案**：填一个**网盘里已共享的文件夹**（不要选整个 `data/`），软件会把自选和盘中横切面按档位写成 JSON 存进去，供几个人共享同一时点的现价。填了目录才启用；之后可以按代码画某个区间的折线、看最近的档口列表。

## 导出、档案库与对照

点「导出 Excel」会先弹出选项，确认后才写文件。**这一步不再向数据方查询**，写的是本机已经有的副本。

当前选中的是一个池子时，弹窗从上到下是：

| 选项 | 怎么用 |
|---|---|
| **导出哪几天** | 这个池子最近留下快照的三天，中间可以空一天。同一天里多次查询或刷新，只保留当天最后一次写入。没取完的那一天也会列出来，并标明已查多少只。默认只勾最新一天，可以多选。一天都不勾时不能确认。没有按天留下的快照时，这里会写明，导出仍用当前打开的副本 |
| **表格里放哪些列** | **和屏幕上一样**（用现在的表头）、**只要价格**（固定六列：名称、代码、最新价、涨跌幅、市盈率（动）、市净率）、**要详细资料**（固定研究列）。后两种跟屏幕上勾了哪些列无关；副本里没有的格子保持空白 |
| **全量后导出** | 和工具栏上的同名勾选是同一个开关，改哪里都会一起变，并且会记住。管查询、全量更新、单独查询、仅查询一次。这一轮开始时记下；进行中再改，只影响下一轮。正常结束才写，用「和屏幕上一样」的列。全量更新是全部页取完才导出一份，不是每一页一份。中途停下、失败、或被新的一轮取代，都不导出 |
| **行情后导出** | 同样会记住，而且和「全量后导出」互不影响。只在刷新行情正常结束时写一份，包括大池里已经取到各页的那次刷新。进行中改勾选只影响下一轮 |

勾了多天时，这几天放进**同一个 Excel**，一天一个工作表，表名就是日期，从新到旧排列。列选项对每一张表都一样。只选最新一天时，内容和导出当前副本一致。

以前只有一个「刷新后自动导出」。那个开关如果当时是开着的，升级后「全量后导出」和「行情后导出」会一起打开。不想让刷新行情也写文件，就把「行情后导出」取消；全量那一边不受影响。

正在看日期框里的旧表、筛选结果或单独查询时，不显示「导出哪几天」，导出的就是屏幕上这份。

- 屏幕上的「—」在 Excel 里是空格子。涨跌幅、60日涨跌幅、年初至今涨幅和屏幕一样：正数带加号，并带百分号。
- 导出的 Excel 会**同时存进档案库**（每人最近 20 份），可随时再下载或预览前几行。
- 档案库里**勾两份**，填一个列名（默认「前十大流通股东」），可以按股票代码对齐看谁变了。
- 导出的 Excel 既能给人看，也能被 Agent 问答当历史资料读。
- 每个池子按上海日期各留一份日快照，供日期框和「导出哪几天」使用。更早的日子如果已经从本机清掉，列表里就不会出现。

## 常见疑问

**Q：票很多的时候，表格是不是只显示了一部分？**  
「查询」一次只取 100 只，要后面的再加载。要整池取完，点「全量更新」或「沪深全部」，不用自己一页一页点。「页码」用来打开已经取完的页。左侧指数和交易所名单很长时，列表一次显示 100 条，点「显示更多」继续。导出当前池子时，写出的是这个池子**已经打开的整份副本**（含已经取过的各页），不是只写屏幕上这一页；还没取过的股票不会为了导出再去查。排序只排当前这一页或已经加载的行，Excel 仍按名单原来的顺序。

**Q：我连点了查询或全量更新，怎么像没反应？**  
上一轮还没结束。这时会提示「这一轮还在进行」，后一次不会再开一轮，也不会把前一次的进度清掉。等状态行写完，或先换成别的池把这一轮停掉，再点下一次。

**Q：状态行写着「还剩多少只没取」，是不是还在跑？**  
看开头。**正在续传**才是这一轮还在做。**现在没有在续传**只是上次留下的记录，后台没有在取数。刷新页面后这行会消失。

**Q：打开创业板或自选，为什么会出现深市、沪市的数字？**  
这一池自己的副本更旧，而更大的池已经盖住了这些股票，软件就把更新的行写进了这一池自己的副本。状态行会写「取自……，已写入这一池的副本」。导出用的也是这份。对方没有覆盖到的股票、以及你自己更晚的格子，都还在。再打开一次如果没有更新的数，不会再写一遍。

**Q：全量后导出和行情后导出有什么区别？**  
全量后导出管查询、全量更新、单独查询、仅查询一次。行情后导出只管刷新行情。两个都在工具栏上，导出弹窗里也有，改一处另一处跟着变，并且会记住。沪深全部弹窗里的勾选跟着你选的刷新方式，改它也会写回对应的开关。一轮开始时记下当时的勾选；进行中再改，只影响下一轮。中途停下或失败不写 Excel。

**Q：沪深全部和自己点两次有什么不同？停在半路会怎样？**  
它按深市、沪市的顺序自动做完，两市不会同时取数，不含北交所。导出开关开着时，每一市结束后先写 Excel，再做下一市；导出没写成，下一市不开始。进行中按钮是「停止沪深」。停在深市时，沪市还没开始。某一页失败时，已经取完的页还能看，下一市也不会开始。

**Q：总市值、流通市值、60日涨跌幅、年初至今为什么空着，或者这一轮特别慢？**  
这四列要在列设置里勾上才会取。批量现价里没有它们，勾上之后会再按股票逐只补，所以大池会慢，也更费授权次数。额度在补的过程中用尽时，没补到的格子保持空白，已经取到的现价不会被擦掉。没勾这四列时，刷新行情不会为它们再请求。

**Q：为什么有的格子是空的？**  
个股没有这个数，或该类数据这个市场没覆盖（比如北交所的财务、股东常常是空的，3日/5日/10日涨跌幅对北交所股票也取不到）。空着是正常行为，不会填假数。

**Q：整张表除了名称和代码，其它格子全是空的，是怎么回事？**  
那是没取到数，最常见的原因是**证书额度用尽**（状态栏会写「证书额度已用尽」），其次是网络不通。分两种证书：**每日刷新**的第二天自动恢复，**长期**的用完就没了，要去「证书池」重新加。可以按 F12 打开控制台，执行 `saDiag()` 看具体是哪一种。

**Q：状态栏显示「证书额度已用尽」是什么意思？**  
数据方给的访问次数用完了，表里就只剩名称和代码。每天会恢复的那类次日自动恢复，不用管；用完就没的那类需要重新添加证书。

**Q：我「固定用这一张」之后，它用完了会怎样？**  
**不会自动换用别的证书**——这是「固定」的意思。软件会停下来告诉你：属于每天会恢复的那类，等到第二天就恢复了；属于用完就没的那类，那张已经从列表去掉，需要重新添加，或者改回「自动换」。如果你希望用完就换下一张，请选「自动换」。

**Q：我点了指数或交易所列表里的股票，怎么没反应？**  
这两个列表只用来看，点它不会加进自选。要加自选请到左侧「自选」页点「+ 添加 / 筛选」搜索。

**Q：加进自选的票能直接分组吗？**  
添加进来的票分组固定是「自选」。想改成「观察 / 备选」，点这只票的名称打开决策卡，在里面改分组；之后规则范围可以按分组来扫。

**Q：导出来不是我想的那批票？**  
看工具栏下面「当前导出：…」。用了「仅查询一次」或「单独查询」之后，导出的是屏幕上这一批，不会改写池子自己的副本。从顶栏点指数进池时，建议先切到左侧「行情」再点。要以前某一天的表，用日期框打开，或在导出弹窗里勾选那一天。

**Q：为什么「全量更新」要慎用？**  
它把当前勾选的列全部向数据方重取，大池还要一页一页取完，最费授权次数。日常补缺用「查询」，盘中等价用「刷新行情」。

**Q：刷新行情之后，有的列没跟着新价格变？**  
行业、财务、股东、3日 / 5日 / 10日涨跌，以及已经有数的离底%，本来就不在「刷新行情」这一轮里。总市值(亿)、流通市值(亿)、60日涨跌幅、年初至今涨幅只有在列设置里勾上才会随这轮更新；勾上后大池会逐只补这四列。这张表不超过 100 只、而且其余列大多还是空的时候，空列会用本机已有结果补上。按钮上的浮注会列出这一轮实际会动的列。

**Q：问答里问了公告或新闻，为什么没有去查？**  
话里要点到「公告」「问董秘」「资讯」「新闻」「政策」或「龙虎榜」，才会查对应的内容。资讯和政策还要先在监控偏好里填检索源。没点到这些词时，不会顺便去查。

**Q：配了规则却没提醒？**  
① 范围是不是限定到了某个分组或某一只；② 是不是只写了文字没选指标（那样不会自动扫描）；③ 盘中只允许实时指标（现价、涨跌、离底、距买区/减仓区），日终规则要等 20:20 那轮；④ 同一条当天不会重复刷——内容是跟上次快照比，没变化就不重复进今日。

**Q：提醒能推到手机上吗？**  
不能。现在只有本机日志和监控中心列表；Webhook 需要在本机配置里填地址才会启用。

**Q：顶栏/状态里出现「离线切片」是什么意思？**  
说明软件没在连数据方，用的是电脑里自带的样例数据（票很少、不是真实行情）。日常使用不会出现；如果是测试人员，请用 `scripts\run-offline.cmd` 启动，用完关掉再双击 `scripts\run.cmd` 回到正常模式。详见[本地部署教程](./本地部署教程.md)。

**Q：怎么退出登录、换一个账号？**  
界面上暂时没有「退出」按钮（这是已知待补的项）。**关掉浏览器标签页**即结束本次登录，重新打开会回到登录页；需要换账号就先关再开。

**Q：数据存在哪、会不会占满磁盘？**  
都在软件文件夹里的 `data/`，顶栏「本机数据」能看到占用，可以一键清缓存、只留最近导出。不要手删 `data/app.db`（自选、对话、提醒都在里面）。
