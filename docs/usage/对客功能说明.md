# 对客功能说明

> 只写你现在打开软件能做什么、故意不做什么。分工见 [`../INDEX.md`](../INDEX.md)。
> 第一次安装请看 [本地部署教程](./本地部署教程.md)。
> 更新日期：2026-09-24

---

## 一句话

这是一套**本机自选助手**：管自己的股票池，看一张分析表，用白话问数，重要变化会记在提醒里。

**不帮你下单，也不保证赚钱。** 打开后默认看你的自选。需要时可以改看某一个交易所的全部挂牌，但沪、深、北是分开导出的，不会合成一张全市场总表。

---

## 先认路：界面地图

打开 `http://127.0.0.1:8765` 登录后，屏幕分成四块：

| 区域 | 在哪 | 干什么 |
|---|---|---|
| **顶栏** | 最上面一行 | 左边是五个主要指数（点位或成份数），右边是你的登录状态 |
| **左侧栏** | 屏幕左边一列 | 选「看哪一批票」：**自选 / 行情 / 交易所**，以及添加自选、搜索、决策卡入口 |
| **主区四个页签** | 屏幕中间上方 | **传统查询**（分析表）、**Agent 问答**（白话问数）、**监控中心**（提醒与规则）、**本机数据**（占用、证书、存档） |
| **弹窗 / 抽屉** | 点按钮后浮出 | 登录、添加自选与筛选、列设置、档案库、添加规则、决策卡（右侧滑出） |

一句话走法：**先在左边选「看哪一批票」→ 中间点「查询」看表 → 需要就「导出 Excel」；想问话就去「Agent 问答」；想知道发生了什么变化去「监控中心」。**

## 顶栏那一行指数

显示 **上证 / 深成 / 北证 / 科创 / 创业**，每 20 秒左右更新一次。

- 上证 = 上证指数、深成 = 深证成指、科创 = 科创50、创业 = 创业板指：显示**点位和涨跌幅**（红涨绿跌）。
- **北证** 一栏显示的是 **「50只」** 这样的数字，不是点位：数据方不提供北证50 的实时点位，所以这里只显示它的官方成份数量。**点一下「北证」，可以直接跳到北证50 这个指数池**（建议先切到左侧「行情」再点）。

## 左侧三个入口：决定「看哪一批票」

三个按钮在左侧栏最上方，同一时刻只有一个生效；查询和导出都跟着当前选中的这一个走。

### 自选（日常用这个）

- 只含你添加过的票。沪、深、北的票会在同一张表里。
- **怎么加票**：点「+ 添加 / 筛选」→ 弹窗里可以按市场（沪市 / 深市 / 科创 / 创业板 / 北交所）筛，也可以按**七大板块、申万一级行业、2026 概念**点选，或搜名称/代码。
  - 弹窗底部三个动作：**加入自选**（追加）、**替换自选**（先清空再写入，会二次确认）、**仅查询一次**（不改自选；这时导出也只含这一批）。
  - 还能自建**自定义概念**（名称 + 关键词），只在本机有效。
- 列表里：点股票**名称**打开右侧决策卡；`↑ ↓` 改顺序（表也跟着这个顺序）；`×` 移出自选；搜索框按名称或代码过滤。

### 行情（指数成份）

- 列出指数芯片：**上证指数、深证成指、北证50、创业板指、中证500、上证50**（都是官方成份名单）。
- **上证指数 ≠ 沪市全部，深证成指 ≠ 深市全部，北证50 ≠ 北交所全部**，点芯片只查/导这一指数的成份股。
- 点芯片后会自动按涨跌幅排好并查一次。
- 科创综指不在官方指数目录里，所以列表里没有它，也不会拿科创板全部来代替。

### 交易所（全市场）

- **沪市全部、深市全部、北交所全部**：一次只出一所，要三张表就点三次。沪市含科创，深市含创业板。
- 下面还有**板块另池**（创业板全部 / 科创板全部）：这是按板块标签筛出来的池，**不是**创业板指 / 科创综指，别混着看。

## 分析表：查询、刷新、导出

### 工具栏按钮（从上到下、从左到右）

| 按钮 | 干了什么 | 什么时候用 |
|---|---|---|
| **查询** | 正常取数：现价优先用本机档，财务/股东这类没过期的字段直接用本机缓存 | 日常就用这个 |
| **刷新** | **只更新现价相关列**，不重拉行业、财务、股东 | 盘中等最新价 |
| **全量更新** | 不管缓存，向数据方重新拉齐全部列 | 觉得数字旧了；**这个最费授权次数，别反复点** |
| **导出 Excel** | 按当前池（或上次「仅查询一次」的那批）取数并下载，同时存进档案库 | 要留档、要给 Agent 读 |
| **列设置** | 勾选要看哪些列，也可以选预设 | 想换视角 |
| **档案库** | 打开本机已导出的 Excel，可再下载、预览、对照 | 找旧文件 |
| **对照上一份** | 直接打开档案库并自动对照最近两份 | 看谁变了 |
| **X日**（日期框） | 配合列设置里的「X日价」，查指定某一天（或之前最近一个交易日）的收盘价 | 想看某天收盘 |

工具栏下面还有一行只读状态：**当前导出范围**（自选 / 某个指数 / 某个交易所 / 筛选一次）和**本次查询的状态**（几只票、什么模式、现价来源、更新时间、有没有告警）。导出前瞄一眼「当前导出范围」，能避免导错一批。

### 表里有哪些列（列设置里勾选）

- **基础**：名称、代码
- **行情**：最新价、涨跌幅、市盈率、市净率、**60日涨跌幅**、**年初至今**、**3日 / 5日 / 10日涨跌幅**、**换手率**、**总市值**、**流通市值**、**X日价**（加粗项默认不勾，需要自己在列设置里打开）
- **公司**：所属行业、七大板块、申万一级、2026 概念、所属概念/板块、主营业务
- **股东**：前十大股东、前十大流通股东
- **财务**：总股本、流通股本、每股净资产、每股收益、每股未分配利润、研发费用、毛利率、净利率
- **资金**：流入、流出、净流入（**北向资金列恒空，见文末**）
- **底顶**：近 1 年底、长窗底、顶、离底%、顶底倍数、目标卖价（默认按「底再涨一半」算）
- **决策卡**：买区低、买区高、减仓价、成本、相对成本%、距买区%、距减仓区%、持有逻辑（默认都不勾）

预设三种：**看盘**（只行情列，默认）、**研究**（含财务股东底顶，约 32 列）、**自定义**（你勾什么就是什么，至少留一列）。

### 排序和列宽

- 点表头的**「代码」或「涨跌幅」**可切换正序/反序（只有这两列能排序）。
- 列宽可以直接拖，会记住。

## 决策卡（给某一只票记参数）

入口：左侧自选列表里**点股票名称** → 右侧滑出抽屉。

可以填：分组（自选 / 观察 / 备选）、持有逻辑、成本、股数、买区低、买区高、减仓价、作废条件。

- 这些只是**这只票的参数**，不会弹窗提醒你；真触发了去「监控中心 → 今日」看。
- 填了买区/减仓价后，可以在「监控中心 → 我的规则」里选「相对决策卡」让系统按它扫描；也可以直接勾决策卡列自己看表。

---

## Agent 问答（用白话问数）

页签：**Agent 问答**。

- 输入框直接说话，Ctrl+Enter 发送。例如：现在什么价、离底部多远、十大股东是谁、有没有分红增发解禁、研发费用和净利率怎么样、属于哪个板块、基金持股里有没有我们盯着的机构。
- 可以**从 Excel 复制一段表格粘贴进来**，或点附件按钮上传 `.xlsx / .csv / .tsv`，按表里的代码来问。
- **「看市场」**按钮：问今天自选盘面怎么样（走另一个策略，会自动带上今日命中与队列）。
- 右栏：**历史对话**（点回之前某一轮）、**本轮引用**（数字来自哪个接口）、**Tool 轨迹**（它调用了什么）、**本机仓库**（档案份数、缓存、日线查询）。
- 本轮问答可以点**导出**存成 Excel。
- 同一轮会记住你刚问过的股票；想换话题点「新对话」。

**能问什么、不能问什么**：它只引用工具取回来的数字，不编；**不荐股、不给目标收益和胜率**；问到「该不该买/卖」时，它只会陈述现价相对你的买区/减仓区和你的规则，**不会给操作指令**。

## 监控中心（不用盯盘，让它记着）

页签：**监控中心**，里面四个子页：**今日 / 规则 / 复盘 / 偏好**。右上角有「立刻跑一轮」。

自动排程：交易日 **09:00–15:00 每 5 分钟**扫盘中规则，**20:20** 跑日终规则并给昨天的命中打次日标签。

### 今日

- **该看**：还没处理的提醒队列（要紧的排前面）。问答里点「看市场」读的是同一个队列。
- **提醒**：命中的具体条目——哪只票、因为什么、当时的关键数字。每条提醒有四个动作：**已看 / 再观察 / 逻辑仍在 / 作废**。

### 规则

**模板规则**（默认开启的这些）：

| 规则 | 什么时候跑 | 说什么 |
|---|---|---|
| 十大股东变动 | 日终 | 有增减；出现你关注的机构会单独点出来 |
| 活跃资金持股 | 日终 | 基金持股里出现你关注的机构 |
| 资金异常 | 日终 | 净流入明显大于近来均值（默认 2 倍） |
| 公司事件（分红/增发/解禁） | 日终 | 有变化，带公告链接 |
| 公告 / 问董秘 | 日终 | 有新增 |
| 涨跌停 / 竞价复盘 | 日终 | 盘后表现与集合竞价量 |
| 龙虎榜上榜 | 日终 | 自选上了当日龙虎榜 |
| **接近底部** | **盘中** | 现价离历史底部很近（默认 8% 内） |
| **接近减仓** | **盘中** | 现价靠近你填的减仓价；没填就用统计目标卖价 |
| **涨停** | **盘中** | 自选出现在当日涨停池 |
| **跌停** | **盘中** | 自选出现在当日跌停池 |

每张规则卡可以：改参数（阈值、范围）、**只跑这条**、开关、保存；「规则定义 / 监控需求」两段文字默认收起，填了会当作问答守则。

**灰着的三条（现在点不开，是故意的）**：期货联动、资讯冲击、产业政策。后两条在你到「偏好」里填了检索源之后会自动解锁；期货那条没有可解锁的路径。

**我的规则**（自己加）：点「添加规则」→ 填名称、选指标、运算符（≤ ≥ =）和阈值、范围（全部自选 / 某个分组 / 某一只）、时机（日终或盘中）、严重度（观察 / 行动）。

- 也可以选「**相对决策卡**」，拿现价去比买区高/买区低/减仓价/成本。
- **不选指标、只写文字**也可以保存：这时它**不会自动扫描**，只作为问答守则。
- 支持「预览」：试跑一次看会不会命中，**不写进提醒**。
- 做不到的：自定义脚本、跨股票或跨列运算、多条件组合、分钟级扫描、时间窗口条件。

### 复盘

给昨天的命中打次日标签：**次日同向 / 次日反向 / 波动不足 / 不按涨跌 / 尚无次日收盘**（下一交易日收盘后才打）。这些标签**只是描述涨跌方向，不是买卖建议**，也不会自动关掉任何规则。可以点「立刻复盘」手动跑。

### 偏好

- **关注机构白名单**：26 家机构（主权基金、稳市资金、投行、基金、ETF）默认全勾，也可以自己加。它只是**对照用的名字表**，不是这些机构的持仓实况。
- **检索源**：你自己填的 http(s) 页面或 RSS（最多 20 条），日终只抓这些地址，命中自选名称/代码（或较长的行业名）才进今日。**不是全网搜索，不做摘要**，内网地址和本地文件会被拒绝。填了之后「资讯冲击 / 产业政策」两条规则才会解锁。
- **提醒通道**（只读）：本机日志、监控中心列表 **恒开**；**Webhook 需要在本机配置里填了地址才会开**，界面上现在不能填。
- **数据插槽**：① 关联期货品种——只有品种**名字**，**没有期货价格**；② 出口占比——查某只票的出口/海外收入占比，只认你上传的本机 csv（可在这页上传），**没有表就是空的**。

## 本机数据

页签：**本机数据**。

- **存储占用**：`data/` 的路径与大小、行情缓存（默认上限约 300 MB，超了先删最久没用的日线）、导出 Excel（每人默认只留最近 20 份）、提醒日志、日线（每只默认最多 500 根，覆盖写）、查询表快照。按钮：**刷新**、**清空行情缓存**（只删可再拉的缓存）、**只留最近导出**。
- **证书池**：两个池——**每日刷新额度**（当日额度用尽自动换下一张，次日恢复）和**长期额度**（总额度用尽后该证书自动移出）；调度模式默认「先用每日池再用长期池」，也可以指定只用一个池或手动指定某张证书。增删证书或改调度会立即生效。
- **墙钟档案**：填一个**网盘里已共享的文件夹**（不要选整个 `data/`），软件会把自选和盘中横切面按档位写成 JSON 存进去，供几个人共享同一时点的现价。填了目录才启用；之后可以按代码画某个区间的折线、看最近的档口列表。

## 导出、档案库与对照

- 导出的 Excel 会**同时存进档案库**（最近 20 份），可随时再下载或预览前几行。
- 档案库里**勾两份**（或用「对照上一份」），填一个列名（默认「前十大流通股东」），可以按股票代码对齐看谁变了。
- 导出的 Excel 既能给人看，也能被 Agent 问答当历史资料读。

## 故意不做

- 自动买卖、接到券商下单
- 「推荐你买这只、能赚多少」
- 一打开就帮你在全市场选股
- 没有数据时编造数字（宁可空着）

提醒只是「规则对上了，值得看一眼」，不是投资建议。买不买仍由你自己决定。

## 常见疑问

**Q：为什么有的格子是空的？**  
个股没有这个数，或该类数据这个市场没覆盖（比如北交所的财务、股东常常是空的）。空着是正常行为，不会填假数。

**Q：导出来不是我想的那批票？**  
看工具栏下面「当前导出：…」。如果上一次用了「仅查询一次」，导出范围就是那一次的那批；另外从顶栏点指数进池时，建议先切到左侧「行情」再点，避免导出范围和屏幕上的表对不上。

**Q：为什么「全量更新」要慎用？**  
它绕过本机缓存重新拉齐全部列，最费数据方授权次数；日常用「查询」，盘中等价用「刷新」。

**Q：配了规则却没提醒？**  
① 范围是不是限定到了某个分组或某一只；② 是不是只写了文字没选指标（那样不会自动扫描）；③ 盘中只允许实时指标（现价、涨跌、离底、距买区/减仓区），日终规则要等 20:20 那轮；④ 同一条当天不会重复刷——内容是跟上次快照比，没变化就不重复进今日。

**Q：提醒能推到手机上吗？**  
不能。现在只有本机日志和监控中心列表；Webhook 需要在本机配置里填地址才会启用。

**Q：顶栏/状态里出现「离线切片」是什么意思？**  
说明软件没在连数据方，用的是电脑里自带的样例数据（票很少、不是真实行情）。日常使用不会出现；如果是测试人员，请用 `scripts\run-offline.cmd` 启动，用完关掉再双击 `scripts\run.cmd` 回到正常模式。详见[本地部署教程](./本地部署教程.md)。

**Q：数据存在哪、会不会占满磁盘？**  
都在软件文件夹里的 `data/`，顶栏「本机数据」能看到占用，可以一键清缓存、只留最近导出。不要手删 `data/app.db`（自选、对话、提醒都在里面）。
