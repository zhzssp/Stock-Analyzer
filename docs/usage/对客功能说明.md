# 对客功能说明

> 只写你现在打开软件能做什么、故意不做什么。分工见 [`../INDEX.md`](../INDEX.md)。
> 第一次安装请看 [本地部署教程](./本地部署教程.md)。
> 更新日期：2026-09-23

---

## 一句话

这是一套**本机自选助手**：管自己的股票池，看一张分析表，用白话问数，重要变化会记在提醒里。

**不帮你下单，也不保证赚钱。** 打开后默认看你的自选。需要时可以改看某一个交易所的全部挂牌，但沪、深、北是分开导出的，不会合成一张全市场总表。

---

## 登录和自选

- 打开后先登录，再进工作台。
- 自选可以添加、删除，也能按名称或代码搜索。左侧列表可用上下箭头改顺序；查询表默认跟这个顺序，点「代码」或「涨跌幅」表头可按该列升降序。
- 点名称打开决策卡：买区、减仓价、成本只是这只票的参数，不会在卡上弹窗。接近减仓由监控「接近减仓」写入监控中心「今日」。
- 添加时可以按市场筛：沪市、深市、科创、创业板、北交所（沪和深可以分开）。
- 也可以按七大板块、申万一级行业、2026 概念点选，或自己在弹窗里加**自定义概念**（名称 + 关键词）。点 2026 概念时先取**官方概念成份**；官方概念树里没有这个节点的，才退回用关键词去对行业 / 概念文字，这时不是官方成份股。
- 筛选结果可以「加入自选」（追加）或「替换自选」（先清空再写入勾选的这些）。「仅查询一次」不改自选；这时点「导出 Excel」导的也是刚看的这一批，不是当前池。
- 侧边有三个入口，查询和「导出 Excel」都跟着当前选中的那一个走：
  - **自选**：只含你勾过的票。自选里若同时有沪、深、北，会在同一张表。
  - **行情**：指数成份。上证指数 / 深证成指 / 北证50 等，**只含该指数成份股**，不是该交易所全部挂牌。
  - **交易所**：沪市全部、深市全部、北交所全部。一次只导当前这一所，要三张表就点三次。沪市含科创，深市含创业板。下面还有「创业板全部 / 科创板全部」两个板块另池，不是创业板指 / 科创综指。
- 工具栏会显示「当前导出：…」，下载的文件名里也会带这个池名。
- 「行情」里的指数成份已经是**官方名单**（上证指数、深证成指、北证50、创业板指、中证500、上证50）。科创综指在官方概念树里没有节点，所以列表里没有它，也不会拿科创板全部来代替。只有断网或没配证书时，才会退回本机切片（比真实行情少）。

## 分析表

点「查询」后，一行一只股票。可以刷新、勾选要看哪些列、导出成 Excel。某格暂时没数就空着，整张表还能用。自选池默认按左侧顺序；指数成份和交易所名单默认按涨跌幅排。点「代码」或「涨跌幅」表头可切换正序/反序。涨跌文字按国内习惯：红涨、绿跌、平盘黑色。

顶栏会显示：现在是离线切片还是在线、有没有配模型 key、提醒走哪些通道（本机日志 / 监控中心列表；Webhook 要在本机配置里开），以及 `data/` 大约占多少磁盘。

「档案库」列出你导出过的 Excel，可以再下一份、预览前几行。至少有两份时，「对照上一份」或在档案库里勾两份，按某一列（默认前十大流通股东）对齐看谁变了。每人默认最多留最近 **20** 份，更早的会在下次导出时清掉；也可以在「本机数据」里立刻只留最近这些。

表上现在有这些列：

**盘面**

- 名称、代码
- 最新价、涨跌幅
- 市盈率、市净率
- 换手率、总市值、流通市值、60日涨跌幅、年初至今涨幅（列设置里默认不勾）
- 3日 / 5日 / 10日涨跌幅（列设置里默认不勾）
- X 日价：在工具栏「X日」选一个日期，再在列设置里勾「X日价」，表里就是那一天（或之前最近一个交易日）的收盘价

**公司和分类**

- 所属行业、主营业务
- 七大板块、申万一级、2026 概念、所属概念 / 板块

**股东和股本**

- 前十大股东、前十大流通股东
- 总股本、流通股本

**财务（薄薄一层）**

- 每股净资产、每股收益、每股未分配利润
- 研发费用、毛利率、净利率

**资金**

- 流入、流出、净流入
- 北向资金这一列现在是空的

**位置（相对自己的历史高低）**

- 近 1 年底、更长一段时间的底、顶
- 离底%、顶底倍数
- 目标卖价（默认按「底再涨一半」来算）

北交所的财务、股东常常是空的，这是正常的。

## 问答

用平常说话问自选里的股票，例如：

- 现在什么价、涨了没？
- 离底部还有多远、目标卖价是多少？
- 十大股东是谁？有没有分红、增发、解禁？
- 研发费用、净利率怎么样？
- 属于哪个板块、主营是什么？
- 基金持股里有没有我们盯着的那些机构？
- 这只大概跟哪些期货品种有关？（只能告诉你品种名字，**没有期货价格**）
- 今天自选盘面怎么样？（点「看市场」，或直接那样问）

也可以从 Excel 复制一表格进来，或上传表格文件，按表里的代码来问。

同一轮对话会记住你刚问过的股票。可以开新对话，也可以从右侧「历史对话」点回之前的一轮。这一轮的问答可以再导出成 Excel。

右侧「本机仓库」能看导出档案份数、行情缓存，以及按代码看日线（来自本机缓存或离线切片）。占用细节在顶栏「本机数据」：路径、各类大小、一键清缓存、只留最近导出。缓存可以随时删，下次查再拉；不要手删 `data/app.db`。

没有的数会直说没有，不会编。期货价格、新闻快讯、北向，现在问了也是没有。出口占比只认本机手工 csv，没表就是空的。

## 提醒

打开「监控中心」，可以立刻跑一轮，也可以对已开启的某一条点「只跑这条」。交易日里也会自动扫盘中实时规则；20:20 跑日终规则，并给**昨天的命中**打次日标签（同向 / 反向 / 波动不足）。股东、资金、事件类不按涨跌打分。标签不是买卖建议，也不会自动关掉规则。命中的会写在本页提醒里：哪只、因为什么、当时的关键数字。同一条规则会拿这次的结果跟上次快照比，没变化就不重复进今日；换了一天或内容有小改动，仍可能再进一条。

「规则」页可以自己**新增 / 删除**条目，也可以关掉某一条。开关、百分比、范围这些数字控件还在，管自动扫描。范围可以是全部自选、某一个分组，或只盯一只自选。每条规则另有「规则定义 / 监控需求」两段文字，默认收起，点开再填；保存后问答助手会当作守则。可以只写文字、不配指标，这时不会自动扫盘，只影响问答。文字不会让盯盘按一段话自由发挥。决策卡上的买区 / 减仓价要拿来扫，请在自定义规则里选「相对决策卡」，或勾列设置里的决策卡列自己看表。

本页还能看到：关注机构白名单（只是对照用的名字）、**检索源**（你自己填的 http(s) 页面或 RSS，日终只抓这些地址）、关联期货品种名字（**没有期货价格**）、出口占比手工表（没有 csv 就是空的；可以上传一份到本机）。监控中心「复盘」页可以立刻再跑一轮打标。

**现在会提醒的：**

- 十大股东有增减；名单里出现我们关注的那些机构时，会单独点出来
- 基金持股里出现我们关注的机构
- 资金净流入明显比近来偏大
- 分红、增发、解禁有变化（会带一个公告网页链接）
- 交易所公告标题、问董秘问答有新增
- 现价已经比较靠近历史底部
- 现价靠近你填的减仓价（没填则靠近统计目标卖价）
- 自选里有股票**当日涨停或跌停**（盘中扫）
- 自选里有股票**上了当日龙虎榜**（盘后）
- 你在偏好里配了检索源之后：资讯冲击 / 产业政策会按白名单 URL 拉取，标题或正文命中自选名称或代码才进今日（带上该页链接；不做摘要、不是全网搜）

上面这些规则默认都是开着的，可以在「规则」页逐条关掉。

**现在不会提醒的：**

- 期货连涨连跌
- 没配检索源时的新闻、产业政策
- 手机或微信推送（提醒只留在这个页面上）

---

## 现在没有

- 每只自选每天的北向资金
- 期货价格，以及据此做的提醒
- 彭博或其它网站的**全网**新闻检索（可以自己在监控偏好填若干 URL，软件只抓这些地址）
- 出口、海外收入占比（没有接第二数据源；只有你上传了本机 csv 才有数）
- 并购、回购起止这类分类提醒

---

## 故意不做

- 自动买卖、接到券商下单
- 「推荐你买这只、能赚多少」
- 一打开就帮你在全市场选股
- 没有数据时编造数字

提醒只是「规则对上了，值得看一眼」，不是投资建议。买不买仍由你自己决定。
