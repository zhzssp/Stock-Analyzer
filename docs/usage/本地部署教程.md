# 本地部署教程（零基础）

> 这份说明只教一件事：把软件装到**你自己的 Windows 电脑**上，并用浏览器打开。
> 装好之后能做什么，请看 [对客功能说明](./对客功能说明.md)。分工见 [`../INDEX.md`](../INDEX.md)。

你不需要会写代码。下面每一步都写了「点哪里、输入什么、成功时长什么样」。

---

## 装好之后是什么样

这个软件**不是**手机 App，也**不是**点一下「安装向导」就出图标的那种程序。

它会在你的电脑上启动一个小服务。你再用浏览器（Edge、Chrome 都可以）打开一个地址，就像打开网页一样使用。这个网页只在你这台电脑上有效，别人用他们的电脑打不开你的。

记住三句话：

1. **关掉黑窗口后助手还在托盘**——右下角小图标。点它可以打开网页；要彻底退出，右键选「退出助手」，或在启动窗口里按 Ctrl+C。
2. **不要双击** `docs\frontend` 里的网页文件。必须先启动软件，再在浏览器地址栏输入下面的地址。
3. **日常只双击一个文件**：`scripts\run.cmd`。第一次会自动配置环境；以后再点，只检查环境然后启动。（另一个 `scripts\run-offline.cmd` 是给测试人员用的，日常不要点它。）

---

## 开始前请确认这 4 件事

请先打开电脑上的「此电脑」（有的电脑叫「我的电脑」），逐条核对：

| 需要什么 | 怎么看 | 不行的话 |
|---|---|---|
| Windows 10 或 Windows 11 | 桌面右下角或设置里能看到 Windows | 目前不支持苹果电脑、手机 |
| 能上网 | 能打开普通网页 | 第一次安装要下载文件 |
| 有 **E: 盘** | 「此电脑」里除了 C: 盘，还能看到 **E:** | 没有 E: 盘时，一键配置会失败。请先准备一块 E: 盘（第二块硬盘、U 盘改盘符，或请身边会电脑的人帮你加一个 E: 盘符），再继续 |
| 桌面还有空位 | 大概再放下几百 MB 就够；E: 盘最好也剩 1 GB 以上 | 磁盘快满时先删一些文件 |

为什么必须有 E: 盘：软件规定运行用的 Python **只能**装在 `E:\python-stock`。其它盘、其它文件夹、电脑里已经装过的 Python，它都不拿来启动服务。

你**不必**自己先去官网装 Python。双击 `run.cmd` 后，脚本会检查；缺了才自动下载并装到 `E:\python-stock`。

## 全程只要做 3 件事

1. 安装 Git（只做一次）
2. 用 `git clone` 把软件文件下载到电脑（只做一次）
3. 双击 `scripts\run.cmd`，等窗口写出「启动成功」，再用浏览器打开并登录

`scripts\setup.cmd` **不是**每天要做的步骤。只有工作人员明确让你「只配置、先不启动」时才单独双击它。

---

## 第 1 步：安装 Git

Git 是一个「把软件文件从网上完整拷到你电脑」的工具。没有它，后面的 `git clone` 无法使用，以后也不能用一条命令更新。

1. 打开浏览器，访问：<https://git-scm.com/download/win>
2. 页面会开始下载安装包。若没有自动下载，点页面上的 **64-bit Git for Windows Setup**。
3. 下载完成后，双击这个安装包。
4. 一路点 **Next（下一步）** 即可。中间有一页问「Git 能不能在命令行里用」，**保持默认选项不要改**。
5. 最后点 **Install（安装）**，装完点 **Finish（完成）**。

怎么确认装好了：

1. 按键盘左下角 **Win** 键（有 Windows 图标的键），输入 `cmd`。
2. 打开「命令提示符」。
3. 输入下面这一行，然后按 **Enter（回车）**：

```bat
git --version
```

如果出现类似 `git version 2.xx.x` 的一行字，就成功了。

如果提示「不是内部或外部命令」，请关掉刚才的黑色窗口，**重新打开一次**命令提示符再试。还不行就再装一遍 Git，并重启电脑。

---

## 第 2 步：把软件下载到桌面（git clone）

建议放到**桌面**，以后好找。

### 2.1 打开「桌面」这个文件夹

1. 用鼠标点桌面上的空白处，不要点图标。
2. 也可以打开「文件资源管理器」（黄色文件夹图标），左侧点「桌面」。

### 2.2 在桌面这个位置打开命令窗口

1. 用鼠标**点一下**桌面文件夹顶部的地址栏（显示着「桌面」或一串路径的那一行）。
2. 地址栏里的字会变蓝。直接输入三个字母：`cmd`
3. 按 **Enter**。

会弹出一个黑色窗口。第一行路径里应能看到 `Desktop`（桌面）。  
**不要关掉这个窗口**，下一步就在这里输入。

### 2.3 输入下载命令

把下面**整行**复制下来（包含 `git clone`），在黑色窗口里右键单击即可粘贴，然后按 **Enter**：

```bat
git clone https://github.com/zhzssp/Stock-Analyzer.git
```

说明：

- 如果工作人员给了你**另一个地址**，把上面这行里的网址换成给你的即可。
- 第一次连接 GitHub 可能要等一会儿，请耐心等，不要连按回车。
- 如果弹出登录窗口，用发给你的 GitHub 账号登录。

成功时长这样：

- 黑色窗口最后不再滚动，重新出现一行可以输入的提示符。
- 桌面上多出一个名为 **Stock-Analyzer** 的文件夹。

打开这个文件夹，里面应能看到 `README.md`、`scripts`、`docs`、`src` 等。看到了就对了。

若等很久没反应、或出现 `Could not resolve host`、`unable to access` 一类英文：多半是这台电脑访问 GitHub 不顺。请把黑色窗口里的完整英文拍下来发给我们。临时办法见文末「备选：用压缩包下载」。

**如果桌面上已经有一份旧的 Stock-Analyzer**：不要再 clone 一次叠在上面。请先打开那个文件夹，按文末「以后如何更新」做 `git pull`，再用新脚本启动。

## 第 3 步：双击 run.cmd（配置环境 + 启动）

这一步会做两件事，中间不用你再点别的：

1. **检查 / 配置环境**（第一次可能要几分钟；已经配好过就很快）
2. **启动服务**（成功后才能打开网页）

### 3.1 怎么点

1. 打开桌面上的 **Stock-Analyzer** 文件夹。
2. 再打开里面的 **scripts** 文件夹。
3. 找到 **run.cmd**。
4. **双击**它。
5. **这个黑色窗口必须一直开着。** 你可以把它缩到任务栏，但不要点右上角的叉。

可能遇到的提示：

- Windows 说「已保护你的电脑」：点 **更多信息**，再点 **仍要运行**。
- 问你要不要允许应用更改：选 **是**。
- Windows 防火墙：选 **允许访问**。
- 若提示没有权限写 `E:\python-stock`：关掉窗口，**右键** `run.cmd`，选 **以管理员身份运行**。

### 3.2 窗口里会先出现英文，这是正常的

最新脚本开头几行是英文，例如：

```text
Stock-Analyzer
Do not close this window.
Checking environment, then starting the server.
Chinese messages will appear below.
Starting run.ps1 ...
```

请继续等。后面会出现中文步骤，例如：

```text
>>> [1/2] 环境检查 / 配置
>>> [1/6] 检查是否有 E: 盘
>>> [2/6] 环境检查
>>> [3/6] 准备 Python 3.11/3.12
```

已经配置成功过的电脑，第 1 步会很快出现 `环境检查通过`，然后自动进入启动。

### 3.3 第一次配置时请特别注意

- 下载 Python 时能看到进度条。没有动也不要关窗口。
- 可能会**另外弹出**一个带进度条的 Python 安装窗口，大约 1～3 分钟。那个窗口也不要关。
- 安装依赖时可能一两分钟没有新字，**这是正常的**。
- 完整过程会写到 `Stock-Analyzer\data\logs` 里。出问题把这个文件夹和黑色窗口一起拍给我们即可。

请等到出现类似下面的字（不必完全一致，意思对即可）：

```text
环境检查通过
启动成功，可以打开浏览器了
http://127.0.0.1:8765
```

或出现「启动成功，可以打开浏览器了」。启动过程中每隔几秒可能出现「仍在启动，已等待 × 秒」。右下角会出现托盘图标。

这时软件已经在本机运行。关掉黑窗口后会留在右下角托盘，去做第 4 步。要彻底退出：托盘右键「退出助手」，或点一下黑窗口按 Ctrl+C。

若窗口停在红色的 `[失败]`：请向上滚动看中文说明，不要只看最后一行英文。常见原因见文末「常见问题」。

## 第 4 步：用浏览器打开并登录

1. 打开 **Microsoft Edge** 或 **Chrome**（不要用微信里的内置浏览器）。
2. 用鼠标点窗口**最上方**可以输入网址的那一长条（叫地址栏）。
3. 删除里面原有的字，输入下面这一行（建议复制粘贴，不要当搜索词去搜）：

```text
http://127.0.0.1:8765
```

4. 按 **Enter**。

能看到登录页就成功了。

默认账号（可复制）：

- 用户名：`hanish`
- 密码：`change-me`

登录后即可使用。功能说明见 [对客功能说明](./对客功能说明.md)。

注意：

- `127.0.0.1` 表示「这台电脑自己」，不是互联网上的网站。
- `8765` 是这个软件占用的门牌号。
- 如果页面打不开：回到第 3 步，看黑色窗口是不是还在、有没有报错。窗口关了就要重新双击 `run.cmd`。
- **不要**进入 `docs\frontend` 去双击 `index.html`。那样看起来像网页，实际上连不上软件。

---

## 第 5 步：用完后怎么关

1. 用鼠标点一下正在运行的那个**黑色窗口**（让它处于选中状态）。
2. 按住键盘 **Ctrl**，再按一次字母 **C**。不必回答 `Terminate batch job (Y/N)?`，也不要连按多次 Ctrl+C。
3. 窗口里出现「正在停止服务」或「服务已结束」，再提示按任意键，按一下即可关掉窗口。
4. 如果直接点了窗口右上角的叉，服务进程也会一并结束；下次启动时还会再清一次残留。
5. 然后可以正常关浏览器。

不要强制结束电脑。下次要再用，从第 3 步重新启动即可。

---

## 第 6 步：第二天、第三天怎么再用

Git 不用再装，配置也不用再做。每次只需：

1. 双击 `桌面\Stock-Analyzer\scripts\run.cmd`（黑色窗口保持打开）
2. 浏览器打开 `http://127.0.0.1:8765`
3. 用原来的账号登录

`run.cmd` 会先检查环境。通过了就直接启动，**不会无故重新下载 Python 或重装依赖**。

## 以后如何更新

工作人员说「请先更新」时，按下面做。不要重新 `git clone` 一份叠在旧文件夹上。

1. 用第 2 步的方法，在 **Stock-Analyzer** 文件夹里打开 `cmd`（注意：是进到这个文件夹里面，不是在桌面）。
2. 输入：

```bat
git pull
```

3. 按 Enter。更新完成后，再双击 `scripts\run.cmd` 启动。

如果 `git pull` 报错，不要自己乱改文件，把英文原文发给我们。

## 常见问题

**Q：双击脚本一闪就没了？**  
说明立刻出错了。请不要双击，改用第 2 步的方法在 `Stock-Analyzer` 文件夹里打开 `cmd`，输入：

```bat
scripts\run.cmd
```

这样窗口不会马上消失，你可以把完整内容拍给我们。日志还在 `data\logs`。

**Q：黑色窗口开头是英文，还出现 `'再启动服务。' is not recognized`？**  
开头几行英文是正常的。若仍出现 `'再启动服务。'`、`' 行。'` 这类「不是内部或外部命令」，说明你用的还是旧脚本。请先按「以后如何更新」做 `git pull`，再双击新的 `scripts\run.cmd`。

**Q：打开网址提示无法访问 / 拒绝连接？**  
先看 `run.cmd` 的黑色窗口还在不在。不在就重新双击启动。还不行，确认地址是 `http://127.0.0.1:8765`，不要写成 `https`，也不要丢了 `http://`。

**Q：登录不进去？**  
用户名和密码区分大小写。请复制本文里的 `hanish` 和 `change-me`，不要手打成中文或多余空格。

**Q：Windows 防火墙弹窗？**  
选「允许访问」。这是软件要在本机开一个端口，不是病毒。

**Q：配置时说找不到 E: 盘？**  
打开「此电脑」确认有没有 E:。没有就不能用当前这一键配置。请先有 E: 盘，再双击 `run.cmd`。

**Q：杀毒软件拦截 Python 安装包？**  
这是 python.org 的官方安装包，会先存到系统临时目录，再装到 `E:\python-stock`。请选择允许 / 信任后，再双击一次 `run.cmd`。

**Q：已经有 `E:\python-stock\python.exe`，却提示找不到 Python 3.11/3.12？**  
不要反复卸载重装 Python，也不要自己再装一份到 C 盘或用户目录指望脚本去用。请先 `git pull` 拿到最新脚本，再双击 `run.cmd`。  
若资源管理器里同时能看到 `E:\python-stock\python.exe` 和 `python312.dll`，说明文件多半已经在；旧脚本试跑失败时会误判。官方安装器若 2 秒就结束，通常是系统认为 3.12 已经装过，**不会**修好试跑失败。

**Q：要不要自己先安装 Python？**  
不必。请让 `run.cmd` 装到 `E:\python-stock`。自己装到别的位置，软件也不会用那一份来启动。

**Q：第一次配置已经成功，还要不要再运行 setup.cmd？**  
不用。以后直接双击 `run.cmd`。只有换电脑、环境坏了、或工作人员让你「只配置、先不启动」时，才单独双击 `scripts\setup.cmd`。

**Q：`run-offline.cmd` 是什么？我要不要点它？**  
不用。那是给测试人员的离线样例启动脚本，数据不是真实行情。日常请双击 `run.cmd`。详见上文「可选（只有测试人员需要）：用离线样例启动」。

**Q：能不能装到手机上？**  
不能。这是电脑上用的本机软件。

## 备选：用压缩包下载（Git 实在装不上时）

1. 浏览器打开：<https://github.com/zhzssp/Stock-Analyzer>
2. 点绿色的 **Code** 按钮，再点 **Download ZIP**。
3. 下载完成后，在「下载」文件夹里找到压缩包，**右键 → 解压** 到桌面。
4. 解压后的文件夹名字可能带 `-master`。请把它重命名为 `Stock-Analyzer`，以免以后不好找。

用压缩包的缺点：以后更新软件不能用一条 `git pull` 命令，需要重新下载解压。能装 Git 的话，请优先用第 2 步。

## 可选（只有测试人员需要）：用离线样例启动

日常使用请双击 `scripts\run.cmd`。**这一节和你无关，除非工作人员明确让你用离线模式测东西。**

`scripts\run-offline.cmd` 是**专门给测试人员**的启动脚本，它和 `run.cmd` 的区别只有一条：

| 脚本 | 谁用 | 数据从哪来 |
|---|---|---|
| `scripts\run.cmd` | 日常使用（绝大多数人） | 连数据商，真实行情，会消耗授权次数 |
| `scripts\run-offline.cmd` | **只给测试人员** | 只用电脑里自带的样例数据，**不联网取行情、不消耗授权次数** |

### 怎么用

1. 打开 `Stock-Analyzer\scripts` 文件夹。
2. 双击 **run-offline.cmd**（要求和 `run.cmd` 一样：黑色窗口保持开着）。
3. 启动后看顶栏：显示 **「离线切片（非实盘）」** 就说明是离线模式。
4. 测完关掉（窗口里 Ctrl+C），下次正常使用**重新双击 `run.cmd`** 即可回到在线。

### 需要注意

- **不需要改任何文件**：离线开关由这个脚本自己带上，不用去改 `.env` 里的 `MAIRUI_OFFLINE`。
- 离线模式下数据是**内置样例**：只有很少几只票，数字不是真实行情。**不要**用它给客户演示，也不要用它导出当真实结果。
- 证书相关的页面在离线模式下不用管；把证书删掉**并不等于**切到离线，别那样试。
- 两个脚本不要同时开着。要换模式，先关掉一个再开另一个。

## 本机数据在哪、会不会把磁盘占满

你的自选、提醒、导出的 Excel、行情缓存，都在软件文件夹里的 **`data/`**，和代码放在一起，方便你打开备份。这一层**不要**拷进 git，也不要发给别人。

- 更新软件用 `git pull` 时，不要删 `data/`，也不要运行会清掉未跟踪文件的命令（例如 `git clean -fdx`）。
- 工作台顶栏有「本机数据」：能看到 `data/` 路径和占用。点「清空行情缓存」只删可再下载的缓存，不动自选和对话。
- 导出的 Excel 默认每人只留最近 20 份；行情缓存默认不超过约 300 MB，超了会先删最久没用的日线。日线只缓存你查过的股票，不会预拉全市场。
- 备份：把整个 `data/` 文件夹拷到 U 盘或另一块盘即可。

和日常打开软件无关的内容（例如接口测试脚本）不在本教程范围。
