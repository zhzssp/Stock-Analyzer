# docs 索引

实现以代码为准。文档打架时只认下表「权威」列，不要两份各写各的。

仓库怎么跑，看根目录 [`README.md`](../README.md)。这里只回答：**先打开哪一份、听谁的。**

```
docs/
├── INDEX.md          ← 你在这里
├── usage/            装软件、打开后能干什么
├── design/           分期、架构、已接接口
├── reviews/          决策闭环要不要做（默认不做）
├── requirements/     客户原话与验收
├── issues/           已核实、尚未关闭的阻塞
├── reports/          脚本生成，勿手改正文
└── frontend/         本机工作台（FastAPI 挂到 /，不要双击 HTML）
```

## 权威

| 问题 | 只认 |
|---|---|
| 做不做、字段清单、接口路径、S0–S9 | **软件设计文档** |
| 用户看见什么、不承诺什么 | **对客功能说明**（能力落地后再改「能用」） |
| 智能体边界、总线、插件契约 | **设计文档**（专论；落地结构仍听软件设计） |
| Agent 外壳/内层、跨日复盘、S8.5 之后分期 | **智能体运行时** |
| 已接接口 URL、licence 坑、官方文档入口 | **API现状** + 验证脚本 |
| 墙钟档口、共享文件夹档案、不租后端如何留盘中横切面 | **墙钟行情账本**（C0–C7 已落地；对客不用 GitHub；冗余查询可接受） |
| 图 1 未闭环是否因官方无源 | **issues/** 对应 P 文件 |
| 2026 / 自定义概念为何不是官方成分 | **issues/** [P-20260921](./issues/P-20260921-概念关键词绑定不确定.md) |
| 工作台是否漏了已有 API 的入口 | **issues/** [P-20260917](./issues/P-20260917-工作台入口与半成品.md) |
| 客户原话与验收 | **requirements/** 对应 R 文件（欠账总表：[R-20260921](./requirements/R-20260921-未完成能力欠账.md)） |
| 怎么装、点哪个脚本 | **本地部署教程** |
| 决策闭环是否开工 | **提效缺口评审** 第 8 节勾选；未勾选不改代码 |
| 工作台长什么样 | **frontend/** |
