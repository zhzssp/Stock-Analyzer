# 本地部署教程（零基础）

> 这份说明只教一件事：把软件装到**你自己的 Windows 电脑**上，并用浏览器打开。
> 装好之后能做什么，请看 [对客功能说明](./对客功能说明.md)。分工见 [`../INDEX.md`](../INDEX.md)。

你不需要会写代码。下面每一步都写了「点哪里、输入什么、成功时长什么样」。

---

## 装好之后是什么样

这个软件**不是**手机 App，也**不是**点一下「安装向导」就出图标的那种程序。

它会在你的电脑上启动一个小服务。你再用浏览器（Edge、Chrome 都可以）打开一个地址，就像打开网页一样使用。这个网页只在你这台电脑上有效，别人用他们的电脑打不开你的。

记住两句话：

1. **黑色小窗口不要关**——那是软件在干活。关掉它，网页就打不开了。
2. **不要双击** `docs\frontend` 里的网页文件。必须先启动软件，再在浏览器地址栏输入下面的地址。

---

## 开始前请确认这 4 件事

请先打开电脑上的「此电脑」（有的电脑叫「我的电脑」），逐条核对：

| 需要什么 | 怎么看 | 不行的话 |
|---|---|---|
| Windows 10 或 Windows 11 | 桌面右下角或设置里能看到 Windows | 目前不支持苹果电脑、手机 |
| 能上网 | 能打开普通网页 | 第一次安装要下载文件 |
| 有 **E: 盘** | 「此电脑」里除了 C: 盘，还能看到 **E:** | 没有 E: 盘时，一键配置会失败。请先准备一块 E: 盘（第二块硬盘、U 盘改盘符，或请身边会电脑的人帮你加一个 E: 盘符），再继续 |
| 桌面还有空位 | 大概再放下几百 MB 就够 | 磁盘快满时先删一些文件 |

为什么必须有 E: 盘：软件规定运行用的 Python 只能装在 `E:\python-stock` 这个位置。其它盘、其它文件夹里的 Python，它都不认。

---

## 全程只要做 4 件事

1. 安装 Git（只做一次）
2. 用 `git clone` 把软件文件下载到电脑（只做一次）
3. 双击 `scripts\run.cmd`（第一次会自动配置，以后只检查环境再启动）
4. 用浏览器打开并登录

---

## 第 1 步：安装 Git

Git 是一个「把软件文件从网上完整拷到你电脑」的工具。没有它，后面的 `git clone` 无法使用。

1. 打开浏览器，访问：<https://git-scm.com/download/win>
2. 页面会开始下载安装包。若没有自动下载，点页面上的 **64-bit Git for Windows Setup**。
3. 下载完成后，双击这个安装包。
4. 一路点 **Next（下一步）** 即可。中间有一页问「Git 能不能在命令行里用」，**保持默认选项不要改**。
5. 最后点 **Install（安装）**，装完点 **Finish（完成）**。

怎么确认装好了：

1. 按键盘左下角 **Win** 键（有 Windows 图标的键），输入 `cmd`。
2. 打开「命令提示符」。
3. 输入下面这一行，然后按 **Enter（回车）**：

```bat
git --version
```

如果出现类似 `git version 2.xx.x` 的一行字，就成功了。

如果提示「不是内部或外部命令」，请关掉刚才的黑色窗口，**重新打开一次**命令提示符再试。还不行就再装一遍 Git，并重启电脑。

---

## 第 2 步：把软件下载到桌面（git clone）

建议放到**桌面**，以后好找。

### 2.1 打开「桌面」这个文件夹

1. 用鼠标点桌面上的空白处，不要点图标。
2. 也可以打开「文件资源管理器」（黄色文件夹图标），左侧点「桌面」。

### 2.2 在桌面这个位置打开命令窗口

1. 用鼠标**点一下**桌面文件夹顶部的地址栏（显示着「桌面」或一串路径的那一行）。
2. 地址栏里的字会变蓝。直接输入三个字母：`cmd`
3. 按 **Enter**。

会弹出一个黑色窗口。第一行路径里应能看到 `Desktop`（桌面）。  
**不要关掉这个窗口**，下一步就在这里输入。

### 2.3 输入下载命令

把下面**整行**复制下来（包含 `git clone`），在黑色窗口里右键单击即可粘贴，然后按 **Enter**：

```bat
git clone https://github.com/zhzssp/Stock-Analyzer.git
```

说明：

- 如果工作人员给了你**另一个地址**，把上面这行里的网址换成给你的即可。
- 第一次连接 GitHub 可能要等一会儿，请耐心等，不要连按回车。
- 如果弹出登录窗口，用发给你的 GitHub 账号登录。

成功时长这样：

- 黑色窗口最后不再滚动，重新出现一行可以输入的提示符。
- 桌面上多出一个名为 **Stock-Analyzer** 的文件夹。

打开这个文件夹，里面应能看到 `README.md`、`scripts`、`docs`、`src` 等。看到了就对了。

若等很久没反应、或出现 `Could not resolve host`、`unable to access` 一类英文：多半是这台电脑访问 GitHub 不顺。请把黑色窗口里的完整英文拍下来发给我们。临时办法见文末「备选：用压缩包下载」。

---

## 第 3 步：第一次配置（可选；直接第 4 步也可以）

这一步只准备环境，不会打开网页。已经配置成功过再跑，会变成**检查**：确认 Python、`.venv`、依赖、`.env` 还在，不再重新下载或重装。

1. 打开桌面上的 **Stock-Analyzer** 文件夹。
2. 再打开里面的 **scripts** 文件夹。
3. 找到 **setup.cmd**。
4. **双击**它。

可能遇到的提示：

- Windows 说「已保护你的电脑」：点 **更多信息**，再点 **仍要运行**。
- 问你要不要允许应用更改：选 **是**。
- 若提示权限不够：不要双击。请用鼠标**右键**点 `setup.cmd`，选 **以管理员身份运行**。

配置过程中，黑色窗口会用中文打印步骤。下载 Python 时能看到进度条。安装 Python、安装依赖时可能一两分钟没有新字，**这是正常的**，请不要关窗口。

请等到最后出现 `配置成功` 或 `环境检查通过`。窗口还会停住，显示请按任意键——看完提示后再按键、关掉即可。

若中途出现「这台电脑没有 E: 盘」：请回到本文开头补上 E: 盘后再试。若出现「下载 Python 失败」：请检查网络后重试。

想省一步：可以跳过本步，直接做第 4 步。`run.cmd` 发现还没配好会先自动配置。

---

## 第 4 步：启动软件（以后每次都用这一步）

1. 仍在 **Stock-Analyzer\scripts** 文件夹里。
2. 找到 **run.cmd**（推荐）。
3. **双击**它。
4. **这个黑色窗口必须一直开着。** 你可以把它缩到任务栏，但不要点右上角的叉。

它会先跑环境检查：已经配好就很快通过；还没配好会先配置再启动。

成功时长这样（不必完全一致，意思对即可）：

```text
环境检查通过
启动成功，可以打开浏览器了
http://127.0.0.1:8765
```

或出现 `Uvicorn running on http://127.0.0.1:8765`。启动过程中每隔几秒可能出现「仍在启动」。

这时软件已经在本机运行。不要关闭窗口，去做第 5 步。

---

## 第 5 步：用浏览器打开并登录

1. 打开 **Microsoft Edge** 或 **Chrome**（不要用微信里的内置浏览器）。
2. 用鼠标点窗口**最上方**可以输入网址的那一长条（叫地址栏）。
3. 删除里面原有的字，输入下面这一行（建议复制粘贴，不要当搜索词去搜）：

```text
http://127.0.0.1:8765
```

4. 按 **Enter**。

能看到登录页就成功了。

默认账号（可复制）：

- 用户名：`hanish`
- 密码：`change-me`

登录后即可使用。功能说明见 [对客功能说明](./对客功能说明.md)。

注意：

- `127.0.0.1` 表示「这台电脑自己」，不是互联网上的网站。
- `8765` 是这个软件占用的门牌号。
- 如果页面打不开：回到第 4 步，看黑色窗口是不是还在、有没有报错。窗口关了就要重新双击 `run.cmd`。
- **不要**进入 `docs\frontend` 去双击 `index.html`。那样看起来像网页，实际上连不上软件。

---

## 第 6 步：用完后怎么关

1. 用鼠标点一下正在运行的那个**黑色窗口**（让它处于选中状态）。
2. 按住键盘 **Ctrl**，再按一次字母 **C**。
3. 如果窗口问 `Terminate batch job (Y/N)?`，输入 `Y`，再按 Enter。
4. 窗口里出现「正在停止服务」或「服务已结束」，然后再提示按任意键，就停干净了。
5. 然后可以正常关浏览器。

不要强制结束电脑，尽量按上面的方法停。下次要再用，从第 4 步重新启动即可。

---

## 第 7 步：第二天、第三天怎么再用

Git 不用再装，配置也不用再做。每次只需：

1. 双击 `桌面\Stock-Analyzer\scripts\run.cmd`（黑色窗口保持打开）
2. 浏览器打开 `http://127.0.0.1:8765`
3. 用原来的账号登录

## 常见问题

**Q：双击脚本一闪就没了？**  
说明立刻出错了。请不要双击，改用第 2 步的方法在 `Stock-Analyzer` 文件夹里打开 `cmd`，输入：

```bat
scripts\setup.cmd
```

或：

```bat
scripts\run.cmd
```

这样窗口不会马上消失，你可以把完整英文拍给我们。

**Q：打开网址提示无法访问 / 拒绝连接？**  
先看 `run.cmd` 的黑色窗口还在不在。不在就重新双击启动。还不行，确认地址是 `http://127.0.0.1:8765`，不要写成 `https`，也不要丢了 `http://`。

**Q：登录不进去？**  
用户名和密码区分大小写。请复制本文里的 `hanish` 和 `change-me`，不要手打成中文或多余空格。

**Q：Windows 防火墙弹窗？**  
选「允许访问」。这是软件要在本机开一个端口，不是病毒。

**Q：配置时说找不到 E: 盘？**  
打开「此电脑」确认有没有 E:。没有就不能用当前这一键配置。请先有 E: 盘，再运行 `setup.cmd`。

**Q：杀毒软件拦截 Python 安装包？**  
这是官方安装包。请选择允许 / 信任后，再运行一次 `setup.cmd`。

**Q：能不能装到手机上？**  
不能。这是电脑上用的本机软件。

**Q：第一次配置已经成功，还要不要再运行 setup.cmd？**  
不用特意再跑。以后直接双击 `run.cmd` 即可：它会先检查环境，通过了就启动服务，不会无故重装。只有换电脑、环境坏了、或工作人员让你「重新配置」时，才再单独跑 `setup.cmd`。

## 备选：用压缩包下载（Git 实在装不上时）

1. 浏览器打开：<https://github.com/zhzssp/Stock-Analyzer>
2. 点绿色的 **Code** 按钮，再点 **Download ZIP**。
3. 下载完成后，在「下载」文件夹里找到压缩包，**右键 → 解压** 到桌面。
4. 解压后的文件夹名字可能带 `-master`。请把它重命名为 `Stock-Analyzer`，以免以后不好找。
5. 然后从本文**第 3 步**接着做（配置、启动、浏览器打开），和第 2 步成功之后完全一样。

用压缩包的缺点：以后更新软件不能用一条 `git pull` 命令，需要重新下载解压。能装 Git 的话，请优先用第 2 步。

---

## 以后如何更新（已会用 git clone 的人）

1. 用第 2 步的方法，在 **Stock-Analyzer** 文件夹里打开 `cmd`（注意：是进到这个文件夹里面，不是在桌面）。
2. 输入：

```bat
git pull
```

3. 按 Enter。更新完成后，再双击 `scripts\run.cmd` 启动。

如果 `git pull` 报错，不要自己乱改文件，把英文原文发给我们。

---

## 可选：以后要看真实行情或更聪明的问答

第一次使用**不必改任何文件**。默认是离线样例数据，也能进工作台。

只有当你拿到了正式数据授权、或 AI 密钥时，才需要改 `Stock-Analyzer` 文件夹里的 `.env` 文件（第一次配置成功后才会出现）。改之前请找工作人员带你改，避免把密钥发到网上。

和日常打开软件无关的内容（例如接口测试脚本）不在本教程范围。
